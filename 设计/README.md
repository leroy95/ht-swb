## 🎯 双轨战略（V2.1）

| 维度 | 轨道A：大众文创 | 轨道B：手工文创 |
|------|:-----------:|:-----------:|
| **一句话** | "先让广胜寺游客觉得——终于有好文创了" | "先做出第一批样品，发小红书，有人下单再做" |
| **首批产品** | 15款（4+6+5） | 3个品类（石膏牌+香囊+蜡烛） |
| **启动资金** | ¥22,000 | ¥3,800 |
| **启动节奏** | 第5周才开始 | 第1周就启动 |
| **盈亏平衡** | 第5个月打平 | 第3个月打平 |
| **核心理念** | 精兵策略——每款都要能卖 | 从入门起步——快上手快出单 |
