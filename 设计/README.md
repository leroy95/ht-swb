# 手作文创——总览

> **定位**：双轨并行——洪洞文创（创新大众线） + 手工文创（高端匠心线）
> **版本约束**：V1.0.0，不升级版本号，只做瘦身、分线和落地化

---

## 1. 两条线的边界

| 维度 | 洪洞文创线 | 手工文创线 |
|---|---|---|
| 一句话 | 让游客觉得“终于有好洪洞文创了” | 先做出能卖的高端样品，再扩展联名与收藏 |
| 价格带 | ¥5–198 | ¥38–1980 |
| 核心场景 | 景区纪念、伴手礼、日常轻礼品 | 礼赠、收藏、唐装/汉服搭配、私域成交 |
| 核心打法 | 走量、复购、景区转化 | 限量、精工、联名、形象款 |
| 主入口 | `设计/02_洪洞地域文创/大众文创产品线.md` | `设计/01_核心产品线/产品矩阵总览.md` |

1. 先看 `../商业计划书.md`

3. 再看洪洞线成本附录：`02_洪洞地域文创/产品手册.md`
4. 再看手工线：`01_核心产品线/产品矩阵总览.md`

## 4. 当前结论

- 洪洞线负责“创新大众化”，目标是卖得动、好补货、好复购
- 手工线负责“高端匠心化”，目标是有质感、有故事、有联名空间
- 执行层只保留一份制作方案，避免多处重复
- README 只做导航，不再堆正文
