## 3. 使用原则

- 总目录只做入口，不承载产品正文
- 洪洞线按“目录 → 产品 → 版本”展开
- 手工高端线只保留总览与单品，不混入洪洞版本
- DIY 体验套装独立成块，不和高端线、洪洞线混淆
- 唐装合作专区独立管理，不回挂核心产品线
- 执行手册只讲怎么做，不重复产品定义
- 所有内容保持 V1.0.0
