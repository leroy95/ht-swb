# 手作文创设计说明（V1.0.0）

> **定位**：本目录的正式入口说明页
> **目的**：统一“产品、计划、执行、专题”的放置规则，避免目录再次分散

---

## 目录结构

```text
设计/
├── 00_索引导航/
├── 01_产品库/
├── 02_计划库/
└── 03_执行手册/
```

---

## 放置规则

### 1. 产品本体放产品库
放到：`01_产品库/`

用于存放真正的产品内容，例如：
- 核心产品线
- 地域文创产品
- 单个产品概览、定位、定义、版本

### 2. 推进计划放计划库
放到：`02_计划库/`

用于存放各类计划，例如：
- 区域计划
- 产品计划
- 合作计划
- 长期规划
- 节日 / 试点 / 上新专项计划

### 3. 执行落地放执行手册
放到：`03_执行手册/`

用于存放具体怎么做，例如：
- 授权策略
- 供应商开发
- 拍摄与内容
- 启动资金
- 每周执行
- 风险应对
- 落地方案

### 4. 专题模块挂到对应库下
专题内容保留独立目录，但统一挂在对应的产品库、计划库或执行手册下，不再另起总库。

### 5. 历史内容进归档
如果后续需要保留旧版本，优先放到归档或改成跳转说明页，不再继续在旧目录扩写正文。

---

## 一句话规则

> **产品进产品库，计划进计划库，执行进执行手册，专题挂到对应库下，旧内容进归档。**

---

## 新增内容前先问自己

- 这是“是什么”？→ 产品库
- 这是“怎么推进”？→ 计划库
- 这是“怎么做”？→ 执行手册
- 这是专题入口？→ 对应专题目录
- 这是历史内容？→ 归档
- 这是统一判断规则？→ `00_索引导航/业务逻辑总览.md`
