# 合作模式与分账

> **一句话**：寄卖为主、不压货款、周结双周结、不爽就撤。

---

## 一、三种合作模式

### 模式一：寄卖铺货（当前主推）

```
我们放货 → 门店卖 → 卖掉的按分成结算 → 卖不掉的原样退回
```

| 项目 | 标准 |
|---|---|
| 分成 | 我们 70-80%，门店 20-30% |
| 结算 | 按周或双周，卖了多少结多少 |
| 库存 | 我们记账，门店签字确认 |
| 退货 | 铺货后 30 天卖不掉，可以取回 |
| 适合 | 所有新渠道，尤其是第一次合作 |

**优点**：门店零风险，愿意试试；我们控制库存
**缺点**：需要定期巡店补货、对账

---

### 模式二：小额批发（渠道验证后再用）

```
门店按批发价买断 → 卖多少都是门店自己的
```

| 项目 | 标准 |
|---|---|
| 批发价 | 零售价的 50-60% |
| 起批 | 每款 30 件起 |
| 结算 | 一手交钱一手交货 |
| 退货 | 除非质量问题，不退货 |

**适用条件**（满足任意一条才谈批发）：
- 该渠道连续 3 周有销量，月均 > 30 件
- 渠道自己主动要求批发
- 渠道距离远，不方便频繁巡店

---

### 模式三：联名定制（远期）

```
门店/景区出 IP + 我们出设计生产 → 独家产品
```

| 项目 | 标准 |
|---|---|
| 适用 | 广胜寺/大槐树官方合作 |
| 分成 | 谈判确定，建议我们 ≥ 50% |
| 启动条件 | 常规寄卖验证成功 + 景区有合作意愿 |

---

## 二、分账规则

### 标准分成表

| 渠道级别 | 门店分成 | 我们分成 | 说明 |
|---|---|---|---|
| A 级（景区商店） | 30% | 70% | 景区流量大，30% 合理 |
| B 级（文旅门店） | 25% | 75% | 门店固定成本低 |
| C 级（咖啡馆/民宿） | 20% | 80% | 非主营，顺手卖 |

### 分账示例

假设一个冰箱贴零售价 ¥20：

| 渠道 | 我们拿 | 门店拿 | 月销 50 个我们收入 |
|---|---|---|---|
| A 级景区 | ¥14 | ¥6 | ¥700 |
| B 级门店 | ¥15 | ¥5 | ¥750 |
| C 级咖啡馆 | ¥16 | ¥4 | ¥800 |

## 三、结算流程

```
┌─────────────────────────────────────┐
│ 每周日/双周日                       │
│ ↓                                   │
│ 媳妇去门店，数一下卖了几个           │
│ ↓                                   │
│ 对照铺货单，算清应回款金额           │
│ ↓                                   │
│ 微信发给门店确认 → 微信/支付宝收款   │
│ ↓                                   │
│ 记账：渠道 + 日期 + 售出 + 回款      │
│ ↓                                   │
│ 如果该补货了，现场补货、更新铺货单   │
└─────────────────────────────────────┘
```

### 对账模板

```
📊 渠道对账 — 2026年X月X日

门店：广胜寺游客中心商店
联系人：张姐 138xxxx

上次铺货日期：X月X日
上次铺货数量：
  冰箱贴 20 个
  明信片 30 张
  书签 20 个

本次盘点：
  冰箱贴 还剩 8 个 → 已售 12 个 × ¥20 = ¥240
  明信片 还剩 15 张 → 已售 15 张 × ¥10 = ¥150
  书签 还剩 12 个 → 已售 8 个 × ¥15 = ¥120
  
应收款：¥240 + ¥150 + ¥120 = ¥510
门店分成 30%：-¥153
应回款：¥357
```

## 四、防踩坑清单

| 坑 | 怎么防 |
|---|---|
| 卖了多少对不上 | 铺货单必须双方签字，数量写死 |
| 门店拖着不给钱 | 第 1 次最多放 3 款各 20 件，压货少 = 风险小 |
| 门店自己降价卖 | 产品必须贴零售价标签，不允许改价 |
| 货被弄丢/弄坏 | 铺货单注明"丢失/损坏照价赔偿" |
| 门店模仿你的产品 | 初始 SKU 打品牌标记（挂卡/包装上有你的品牌名） |
| 门店说不卖了但货没了 | 铺货单有明确日期和数量，追不回来就止损 |

## 五、退出机制

满足以下任一条件，把货收回，停止合作：

- 连续 30 天零销量
- 累计 2 次回款延迟超过 2 周
- 门店私自降价销售
- 产品被仿冒且门店不配合追查

> 退出很简单：微信说一声，去把剩下的货拿回来，不撕破脸也不纠结。渠道有的是。
