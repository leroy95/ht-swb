# 景区联络清单

> 洪洞 + 临汾可铺渠道汇总，按优先级排列

---

## A 级：核心景区

### 广胜寺

| 项目 | 内容 |
|---|---|
| 地址 | 洪洞县城东北 17 公里广胜寺镇 |
| 营业时间 | 8:00-17:30（夏季）/ 8:30-17:00（冬季） |
| 门票 | ¥55 |
| 合作目标 | 游客中心商店、飞虹塔周边摊位 |
| 怎么找负责人 | 进景区 → 到游客中心 → 找到商店 → 问店员或收银"老板在吗" |
| 最佳上门时间 | 工作日 10:00-11:00（人少，老板有空） |
| 带什么 | 样品 3 款各 2 个 + 铺货单 + 笔 + 手机产品图 |
| 心理价位 | 零售价的 30% 给商店 |

### 大槐树寻根祭祖园

| 项目 | 内容 |
|---|---|
| 地址 | 洪洞县城北公园街 |
| 营业时间 | 8:00-18:00 |
| 门票 | ¥80 |
| 合作目标 | 景区出口商店、祭祖园内摊位 |
| 怎么找负责人 | ① 以游客身份进景区，逛到出口商店 ② 观察谁在管店 ③ 上前问 |
| 最佳上门时间 | 工作日 14:00-15:00（游客相对少） |
| 注意 | 旺季极旺（清明节/暑假/十一），铺货要多备 |

### 苏三监狱（明代监狱）

| 项目 | 内容 |
|---|---|
| 地址 | 洪洞县城内古槐南路 |
| 门票 | ¥40 |
| 合作目标 | 门口商店或售票处旁边摊位 |

## B 级：文旅门店

### 洪洞古城/老街区域

| 店名/位置 | 类型 | 备注 |
|---|---|---|
| 老街入口第一家文创杂货铺 | 文创 | 先去看一次，观察是否有寄卖可能 |
| 老街中段书店+咖啡馆 | 书店/咖啡 | 两类客群都覆盖 |
| 老街尾部工艺礼品店 | 工艺礼品 | 受众更偏游客 |

> 老街适合"扫街"——带样品包从街头走到街尾，每家进去问一句。

### 咖啡馆/茶馆

| 点名方向 | 位置 | 备注 |
|---|---|---|
| 瑞幸/库迪等连锁 | 洪洞县城 | 连锁店一般不接寄卖，但可以试试放门口 |
| 独立咖啡馆（1-2 家） | 县城中心 | 老板通常好沟通，愿意支持本地手作 |
| 洪洞本地茶馆 | 古城附近 | 茶客 = 文化消费群体，匹配度高 |

### 民宿/客栈

| 区域 | 备注 |
|---|---|
| 广胜寺周边民宿（2-3 家） | 住客是景区游客，购买意愿强 |
| 大槐树周边客栈 | 同上 |
| 洪洞县城 Airbnb/途家房源 | 可联系房东，放一套展示品 |

### 其他文化点位

| 点位 | 联系人方向 |
|---|---|
| 洪洞县图书馆 | 问前台是否有文创展示区 |
| 洪洞博物馆（如有） | 博物馆商店 |
| 洪洞县文化馆 | 可能有非遗/手工艺展示窗口 |
