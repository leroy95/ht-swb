# 执行清单（可直接打印）

> 每完成一项就打勾 ✅

---

## 第 10 周：准备周

- [ ] 打印铺货单 20 份
- [ ] 制作零售价标签（每款 50 个，尺寸 2cm × 4cm）
- [ ] 准备 3 个"上门样品包"（每款 2 个样品）
- [ ] 准备好手机里的产品图集（方便一口气展示）
- [ ] 记熟合作话术（见话术卡），至少练习 2 遍
- [ ] 去广胜寺踩点（以游客身份逛商店）
- [ ] 去大槐树踩点
- [ ] 去老街踩点
- [ ] 记录踩点观察：竞品类型 / 价格 / 是否有寄卖可能

---

## 第 11 周：铺货周

- [ ] 准备好第一次铺货的货（3 款 × 20 件 × 3 个渠道 = 180 件）
- [ ] 去广胜寺游客中心 → 找负责人 → 放货 → 签铺货单
- [ ] 去大槐树景区 → 同上
- [ ] 扫洪洞老街 2-3 家文创店 → 同上
- [ ] 扫精品咖啡馆 1-2 家 → 同上
- [ ] 每铺完一个渠道，立刻微信向远程同步结果
- [ ] 当天回家后更新渠道 Excel 表

---

## 第 12 周：巡店 + 对账周

- [ ] 回访广胜寺 → 数库存 → 对账 → 收款/补货
- [ ] 回访大槐树 → 同上
- [ ] 回访老街门店 → 同上
- [ ] 回访咖啡馆 → 同上
- [ ] 各渠道对账汇总，算出本周回款
- [ ] 支付宝/微信收到回款后记账
- [ ] 判断哪些渠道需要补货，补多少
- [ ] 尝试新增苏三监狱/图书馆等渠道

---

## 第 13-16 周：优化期

- [ ] 每周至少 1 次巡店（把所有渠道跑一遍）
- [ ] 每次巡店：数库存、对账、收款、补货
- [ ] 第 14 周：识别爆款渠道组合
- [ ] 第 14 周：收回滞销款的货（≥30 天零销量）
- [ ] 第 15 周：优化陈列（和门店商量放更好位置）
- [ ] 第 16 周：全面复盘报告（发给远程）
- [ ] 第 16 周：决定是否启动联名/批发

---

## 每月常规

- [ ] 渠道回款总额统计
- [ ] 各渠道销量排名（Top 3 公布）
- [ ] 各产品在各渠道销量排名
- [ ] 渠道评分更新（A/B/C 级调整）
- [ ] 新增渠道记录（如有）
- [ ] 退出渠道记录（如有）

---

## 紧急情况应对（何时立刻联系远程端）

- [ ] 门店说"不想卖了" → 问原因，同步远程
- [ ] 有人找你批发（买断） → 不要当场答应，同步远程
- [ ] 有人想联名/定制 → 记录需求，同步远程
- [ ] 货丢了/被弄坏了 → 按铺货单核算损失，同步远程
- [ ] 有客户投诉质量问题 → 道歉、收回、换新、同步远程
