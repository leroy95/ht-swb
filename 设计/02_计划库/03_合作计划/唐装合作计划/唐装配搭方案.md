# 👘 唐装配搭手工文创方案（V2.0.0）

> **定位**：手工文创线的高端联名、门店合作与礼赠延展模块
> **一句话**：把唐装/旗袍/汉服的"单件服装消费"，延伸成"配饰 + 礼品 + 会员复购"的高客单组合
> **目标**：做得出来、卖得出去、门店愿意推、顾客愿意二次买
> **当前状态**：🟡 远期储备 — 等洪洞线+手工线跑通后启动（预计第 16 周+）
> **执行模式**：个人工作室 · 媳妇（洪洞）上门谈店 + 本人（北京）远程决策
>
> 配套新文件：`00_计划概览.md` / `启动条件与时机.md` / `角色分工与执行清单.md`

## 0. 个人工作室适配说明（V2.0 新增）

> **这一节是 V2.0 新增的，说明在"媳妇本地执行+我远程支持"模式下，唐装合作为什么要等、以及怎么落地。**

### 0.1 为什么是远期储备

本方案（产品、定价、合作模式）本身经得起推敲，但**启动时机必须等**：

| 前置条件 | 预计满足时间 | 为什么必须先达成 |
|---|---|---|
| 洪洞线回款 ≥ ¥3,000 | 第 10-12 周 | 证明文创产品方向可行，才敢投入第二条线 |
| 手工线月出货 ≥ 20 件 | 第 4-8 周 | 媳妇先要练手工基本功，香囊制作需要 2-4 周上手 |
| 媳妇已完成 ≥ 10 个香囊 | 第 8 周前后 | 没有成品，没法带样品去唐装店谈 |

### 0.2 最小启动模型

不是全方案上马，而是：

```
第 16 周 → 找 1 家唐装店 → 只带香囊 → 寄卖分成 7:3 → 每周巡店
     ↓ 4 周后
卖得动 → 加发钗 → 再 4 周后 → 加压襟 → 再 4 周后 → 谈联名
卖不动 → 换一家店试试 → 还是卖不动 → 改定价/款式/颜色
```

### 0.3 与总预算的关系

| 阶段 | 预算来源 | 金额 |
|---|---|---|
| 样品打样 | 机动金 | ¥200-400 |
| 首批 50 个香囊 | 机动金或手工线回款 | ¥650-1,050 |
| 后续扩款 | 唐装线自身回款（滚动） | 自己养自己 |

> 唐装线不单独占用 ¥30,000 中的大额预算。启动成本从机动金垫 ¥500-1,500，后续用自身回款滚动。

## 1. 合作目标与边界

### 1.1 我们要解决什么
- 唐装店卖衣服，但顾客常常缺少完整搭配
- 顾客买完衣服后，缺少可复购的配饰与礼赠延展
- 手工文创缺少明确的高客单展示场景
- 门店想要“能摆、能讲、能成交”的轻量商品，但不想压大货

### 1.2 我们要达成什么
- 帮唐装店提升客单价和试戴转化
- 帮顾客降低搭配决策成本
- 帮手工文创建立“穿搭 + 礼赠 + 会员复购”闭环
- 以小样本快速验证，不做重资产、重压货合作

### 1.3 不做什么
- 不一上来就做大规模联名工厂化铺货
- 不为了联名而联名，避免把产品做复杂
- 不把门店变成“样品仓库”，不做无结算、无回收、无责任的陈列

## 2. 合作对象与适配场景

### 2.1 适合合作的对象
- 本地唐装店
- 旗袍店
- 汉服工作室
- 国风旅拍门店
- 婚庆礼服工作室
- 文旅景区里的国风体验店

### 2.2 最适合的场景
- 春节拜年穿搭
- 国庆出游拍照
- 婚礼、订婚、回门、年会
- 旅拍、汉服妆造、节日礼赠
- 门店试戴、搭配推荐、会员复购

### 2.3 判断适不适合合作的 4 个条件
1. 店里确实有“搭配需求”
2. 店员愿意帮忙推荐，不只是摆着看
3. 顾客愿意试戴、愿意拍照、愿意下单
4. 门店愿意给到明确的陈列位或成交位

## 3. 优先推荐产品与产品细节

> 先从低风险、好解释、易成交的产品开始，再扩展到更高客单的配饰和礼盒。

### 3.1 古法香囊（优先级最高）
**定位**：最适合第一次合作的入门款，也是节日礼赠最容易成交的款。

**产品细节**
- 形态：方形、葫芦形、圆形
- 尺寸：6–8cm 左右
- 材质：真丝 / 缎面 / 棉麻 + 香粉 + 流苏
- 香方：檀香、柏木、丁香、艾草、薄荷、陈皮
- 颜色：红金、琉璃蓝、米白、青绿
- 工艺：裁片、缝制、填香、封口、配流苏、装袋

**核心卖点**
- 文化感强，容易讲故事
- 材料容易买，学习成本低
- 适合春节、唐装、日常、走亲访友
- 可以做成“包挂 / 衣襟挂件 / 礼盒配件”三用款

**建议价格**
- 零售价：¥68–98
- 批发价：¥38–48
- 成本控制：¥13–21

**可做版本**
- 日常款：简洁、轻量、适合试售
- 唐装联名款：用门店面料余料做外袋或边饰
- 节日礼盒款：加祝福卡、礼袋、香型说明卡

---

### 3.2 琉璃色发钗
**定位**：试戴成交最强的视觉款，适合门店陈列。

**产品细节**
- 形态：单支 / 双支
- 材质：UV 树脂 + 珠光粉 + 合金钗杆
- 配色：琉璃蓝、朱红、青绿、金色
- 风格：轻国风、节庆、旅拍、婚礼副妆
- 工艺：配色、灌制、固化、打磨、装配

**核心卖点**
- 一眼能看出“适合唐装/旗袍”
- 上头效果明显，试戴率高
- 适合拍照、出片、提升门店氛围

**建议价格**
- 零售价：¥88–128
- 批发价：¥45–58
- 成本控制：¥14–20

**可做版本**
- 试戴款：单支快销
- 成对款：适合礼赠和双人搭配
- 节日限定款：春节红金、国庆琉璃蓝

---

### 3.3 合香压襟
**定位**：高客单形象款，适合礼赠、晚宴、婚礼和收藏。

**产品细节**
- 形态：一主石 + 配珠 + 流苏
- 材质：合香丸 / 珠料 / 玉石碎片 / 编绳 / 金属配件
- 风格：古典、端庄、礼感强
- 工艺：选珠、编结、配色、装配、整理、包装

**核心卖点**
- 有明显“高端感”
- 是唐装搭配里最容易被看到的视觉点
- 客单高，适合做品牌形象

**建议价格**
- 零售价：¥258–358
- 批发价：¥98–128
- 成本控制：¥33–49

**可做版本**
- 礼赠款：适合节日、婚礼、年会
- 收藏款：少量编号
- 联名款：加入门店专属元素

---

### 3.4 天然植物染真丝丝巾
**定位**：穿搭型高客单，适合做礼盒和会员延展。

**产品细节**
- 版型：68cm / 90cm
- 材质：真丝坯布
- 图案：飞虹塔轮廓、壁画色谱、金藏文字边框
- 工艺：设计分色、染色、固色、蒸洗、手工卷边

**核心卖点**
- 和唐装、旗袍、汉服天然兼容
- 比纯配饰更有“礼感”和“体面感”
- 易做成门店展示主视觉

**建议价格**
- 零售价：¥228–980
- 批发价：按版型和工艺单独定
- 成本控制：¥60–120

**可做版本**
- 试水款：68cm 小方巾
- 主力款：90cm 大方巾
- 礼盒款：丝巾 + 话术卡 + 祝福卡

### 4.2 第二阶段再加 1 款
- 天然植物染真丝丝巾

原因：
- 客单更高
- 更适合作为节日礼盒和会员礼
- 能把搭配提升到“整套解决方案”

## 5. 合作模式设计

### 5.1 模式A：样品展示 + 试戴成交
**适合场景**：第一次合作、彼此不熟、先验证成交。

**流程**
1. 先做 3 款样品
2. 门店选款，摆 4–6 件样品
3. 顾客试戴 / 试闻 / 试配
4. 门店直接成交或扫码下单
5. 2–4 周后复盘销量

**合作特点**
- 风险低
- 门店无需压货
- 我方能快速验证产品和价格

---

### 5.2 模式B：小批订货 + 正常补货
**适合场景**：样品验证后，确认卖得动。

**建议首单**
- 50–100 个香囊
- 20–50 支发钗
- 10–30 件压襟
- 10–20 条丝巾试点

**首付款建议**
- 首单定制或首批订货：**50% 定金**
- 出货前结清尾款：**50%**

**为什么是 50%**
- 覆盖材料和前期人工
- 避免我们先垫太多
- 也能筛掉不认真合作的门店

---

### 5.3 模式C：寄售 / 渠道互置
**适合场景**：门店客流好，但不想压货。

**做法**
- 门店放 4–6 个样品
- 顾客下单后由我们发货
- 按月或按半月结算

**分成建议**
- 门店抽成：20%–30%
- 我方保留：70%–80%

**建议收取**
- 样品押金：500–2000 元
- 陈列保证金：可抵首批货款

---

### 5.4 模式D：联名定制
**适合场景**：已经有销量，准备做专属款。

**联名内容**
- 唐装店专属配色
- 唐装店 LOGO 吊牌
- 余料外袋 / 包边 / 流苏
- 专属祝福卡
- 节日限定礼盒

**额外收费**
- 设计开发费：500–3000 元
- 视复杂度、图稿量、打样轮次而定

**首付建议**
- 定制联名：**50% 定金**
- 批量确认后再补尾款

## 10. 合作流程建议（V2.0 · 含个人工作室适配）

### 10.1 第一次谈合作（媳妇版）

媳妇的操作顺序（不需要懂销售，跟着做就行）：

1. **踩点**：逛街时留意唐装/旗袍/汉服店，记下位置和店名，拍张门口照片发给我
2. **准备**：我带 3-5 个香囊样品 + 价格牌 + 故事卡（我提前寄到洪洞）
3. **进门**：选下午客人少的时候，直接找老板/店长，按话术卡说第一句
4. **摆样品**：把香囊放在柜台/试衣区旁边，让老板能看到实物
5. **谈分成**：寄卖模式，门店 20-30%，卖一个结一个
6. **加微信**：不管成不成，先加微信
7. **反馈**：回家后微信告诉我：老板反应 / 有没有留样品 / 要不要跟进

### 10.2 第一次签单（简化版）

不用签正式合同，一张铺货单就够了：

| 铺货单写什么 | 说明 |
|---|---|
| 铺货日期 | 哪天放的 |
| 产品名称 + 数量 | 古法香囊 × 6 个 |
| 零售价 | ¥88/个 |
| 分成比例 | 门店 25%，我方 75% |
| 结算方式 | 微信转账，每周结一次 |
| 双方微信/手机号 | 方便联系 |

> 正式合同版参见《唐装合作协议要点.md》

### 10.3 复盘标准（媳妇版）

媳妇只需要回答我 4 个问题：
1. 哪个颜色被顾客拿起来看的次数最多？
2. 有没有顾客问"有没有发钗/压襟"？
3. 哪个店员最愿意帮我们推荐？
4. 这两周卖了几个？收了多少钱？

> 我做数据分析，媳妇负责告诉我"发生了什么"。

## 11. 合作风险与控制

| 风险 | 表现 | 应对 |
|---|---|---|
| 卖不动 | 看的人多，买的人少 | 先缩款，改价格带，先做香囊 |
| 门店不推 | 样品放着没人管 | 用店员激励和试戴机制 |
| 压货 | 门店库存积压 | 改成小单补货或寄售 |
| 定制跑偏 | 颜色、图样不一致 | 先确认样品，再定量产 |
| 结算拖延 | 回款慢 | 首单 50% 定金，明确账期 |

---

## 12. 可行性判断

- 工艺路径成熟，能在现有供应链完成
- 香囊、发钗、压襟都适合小批量试点
- 适合“先样品、后小批、再放量”的稳健策略
- 唐装合作要先从配搭补全切入，不要一开始就重联名

## 13. 最终建议（V2.0 · 含启动节奏）

### 如果现在就开始准备（而不是现在就开始谈）
- 第 1-8 周：媳妇专注洪洞线 + 手工线，同时学做香囊
- 第 9-12 周：夜市先验证香囊定价，收集顾客反馈

- 第 16 周：启动！媳妇带香囊样品进店谈

### 如果想做得更稳
- 第 16 周只找 1 家店、只放香囊
- 卖够 20 个再考虑加发钗
- 发钗卖够 15 支再考虑加压襟
- 压襟卖够 10 件再谈联名

### 不要做的事情
- ❌ 不要一开始就同时做香囊+发钗+压襟
- ❌ 不要在没有样品的情况下去谈
- ❌ 不要在洪洞线还没回款时就启动唐装线
- ❌ 不要为了签约而降价
