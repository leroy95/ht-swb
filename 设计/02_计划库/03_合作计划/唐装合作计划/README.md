## 合作逻辑（V2.0 更新）

1. **先等，后动**：洪洞线回款 ≥ ¥3,000 + 手工线月出货 ≥ 20 件 → 再启动
2. **先 1 家店，后扩展**：第一家店验证通过再找第二家
3. **先 1 款，后加款**：香囊稳定 → 加发钗 → 加压襟 → 谈联名
4. **先寄卖，后批发**：不压货不压款，卖一个结一个
5. **媳妇跑店，我决策**：媳妇带样品上门、巡店收钱；我定价格、判数据、做决策

## 使用原则

1. 所有合作都要落到"谁做、做什么、多少钱、多久做完"
2. 门店反馈弱时，先改配搭和话术，不急着扩 SKU
3. 正文只放本专题内容，不与核心产品线混写
4. 若后续产品化，在 `01_产品库/` 下另建目录，本目录保持合作视角
5. **不满足硬条件不启动**（洪洞线回款 + 手工线出货 + 媳妇已掌握香囊制作）
