## 合作逻辑

1. 先样品，再小批，再联名
2. 先门店试戴，再谈放量
3. 先看成交，再谈会员和礼盒
4. 所有合作都要落到“谁做、做什么、多少钱、多久做完”
5. 如果门店反馈弱，先改配搭和话术，不急着扩 SKU
