# 唐装合作首单打样清单（V1.0.0）

> **用途**：把唐装合作第一单需要准备什么、确认什么、检查什么，整理成可直接执行的打样表
> **适用场景**：第一次合作、样品确认、小批试产、首单下单前

---

## 1. 首单目标

### 1.1 这次打样要解决什么
- 确认产品做出来是否好看
- 确认配搭是否适合唐装 / 旗袍 / 汉服
- 确认门店是否愿意摆、愿意推、愿意试戴
- 确认首单价格、结算方式、包装形式是否合适

### 1.2 首单打样原则
- 先样品，后下单
- 先 3 款，后扩展
- 先确认外观，再确认价格
- 先确认门店成交，再确认联名

## 3. 首单准备表

| 阶段 | 要准备什么 | 要确认什么 | 要检查什么 | 责任人 |
|---|---|---|---|---|
| 选款前 | 门店风格、顾客年龄段、主打服装颜色 | 是否适合唐装/旗袍/汉服 | 是否有明确搭配需求 | 我方 + 门店 |
| 图稿阶段 | 设计图、色卡、尺寸草图 | 图案是否能看懂、能上身 | 是否过于复杂、是否失真 | 我方 |
| 打样阶段 | 面料、香料、配件、包装材料 | 工艺能否实现、成本是否合理 | 样品外观、手感、颜色、异味 | 我方 + 供应商 |
| 门店确认 | 样品、价格牌、故事卡 | 门店是否愿意展示/试戴 | 陈列位置、试戴位置、扫码位 | 门店 |
| 下单前 | 首单数量、结算方式、交期 | 是否接受 50% 定金 | 是否写清交货时间和补货规则 | 双方 |
| 发货前 | 成品、包装、说明卡、礼袋 | 包装是否像礼品 | 数量是否齐套、标签是否正确 | 我方 |
| 到店后 | 上架样品、陈列说明、话术卡 | 店员是否会介绍 | 样品是否完好、是否好拿取 | 门店 |

## 4. 打样确认清单

### 4.1 设计确认
- [ ] 产品名称是否确定
- [ ] 尺寸是否确定
- [ ] 颜色是否确定
- [ ] 主视觉是否确定
- [ ] 是否需要门店 LOGO
- [ ] 是否需要余料联名

### 4.2 工艺确认
- [ ] 香囊香方是否确定
- [ ] 发钗材质是否确定
- [ ] 压襟配珠是否确定
- [ ] 丝巾版型是否确定
- [ ] 包装是否可量产
- [ ] 说明卡是否能印清楚

### 4.3 成本确认
- [ ] 材料成本是否可接受
- [ ] 包装成本是否可接受
- [ ] 人工成本是否可接受
- [ ] 批发价是否给门店留足毛利
- [ ] 首单是否覆盖打样和开模成本

### 4.4 合作确认
- [ ] 是订货还是寄售
- [ ] 定金比例是否确定
- [ ] 抽成比例是否确定
- [ ] 押金是否收取
- [ ] 设计费是否单列
- [ ] 退换规则是否写清

---

## 5. 打样检查表

### 5.1 外观检查
- [ ] 颜色是否与色卡一致
- [ ] 做工是否整齐
- [ ] 有无毛边、脱线、掉色、裂痕
- [ ] 是否有明显廉价感
- [ ] 是否适合拍照出片

### 5.2 使用检查
- [ ] 香囊是否闻起来稳定、不冲鼻
- [ ] 发钗是否好夹、不易掉
- [ ] 压襟是否有重量感和垂坠感
- [ ] 丝巾是否顺滑、是否容易起皱
- [ ] 是否适合试戴和日常使用

### 5.3 包装检查
- [ ] 是否有礼品感
- [ ] 是否便于陈列
- [ ] 是否便于携带
- [ ] 是否有品牌卡 / 故事卡 / 说明卡
- [ ] 是否适合门店直接摆放

### 5.4 安全检查
- [ ] 是否有小零件脱落风险
- [ ] 是否有过敏风险提示
- [ ] 是否有易燃风险提示
- [ ] 是否有锐角或扎手问题
- [ ] 是否需要儿童场景提醒

## 6. 首单谈判执行表

| 项目 | 建议值 | 备注 |
|---|---|---|
| 首付款 | 50% | 订货型和联名型都建议这样做 |
| 尾款 | 出货前结清 | 防止压款 |
| 寄售抽成 | 20%–30% | 门店愿推才有意义 |
| 样品押金 | 500–2000 元 | 可抵后续货款 |
| 设计费 | 500–3000 元 | 联名定制时单列 |
| 试点周期 | 2–4 周 | 够看成交数据 |
| 首单数量 | 50–100 件起 | 先小单验证 |

## 7. 首单交付物

### 我方交付
- 样品
- 价格牌
- 故事卡
- 包装
- 说明卡
- 扫码牌 / 试戴卡
- 售后对接人

### 门店交付
- 陈列位
- 试戴位
- 店员推荐
- 反馈数据
- 销量记录

---

## 8. 到店后复盘表

### 8.1 需要记录的数据
- 问询率
- 试戴率
- 成交率
- 客单价
- 哪个款最好卖
- 哪个颜色最好卖
- 哪种包装最像礼盒
- 店员是否愿意主动推荐

### 8.2 复盘结论
- 卖得动：补货
- 问得多但买得少：改价格或改款式
- 店员不推：改陈列或加激励
- 包装不好卖：先改包装再扩单

---

## 9. 一页总结

### 首单先做什么
- 先做 3 款样品
- 先找愿意试戴的门店
- 先做 50–100 件小单
- 先收 50% 定金
- 先跑 2–4 周试点

### 首单最关键的 5 件事
1. 样品好不好看
2. 门店愿不愿意摆
3. 店员会不会推
4. 顾客愿不愿意试戴
5. 价格和结算能不能接受

> 这份清单就是为了把“第一单”从想法变成可执行动作。
