# 唐装合作 — 启动条件与时机

> **版本**：V2.0.0
> **原则**：不验证不投入，先跑通洪洞线和手工线再说唐装线

---

## 1. 为什么不现在启动

### 三个前置条件，目前都不满足

| 前置条件 | 当前状态 | 预计满足时间 |
|---|---|---|
| 媳妇已熟练制作香囊 | ❌ 还没开始学 | 第 5 周后（洪洞打样期同步学） |
| 洪洞线已产生稳定回款 | ❌ 还没下生产线 | 第 10-12 周 |
| 手工线月稳定出货 | ❌ 刚起步 | 第 4-8 周验证 |

### 当前预算也不能分心

| 预算使用者 | 金额 | 周期 |
|---|---|---|
| 洪洞线打样+大货+包装 | ¥17,600 | 第 5-10 周 |
| 手工线材料+营销 | ¥2,500 | 第 1-4 周 |
| 媳妇生活贴补 | ¥3,000 | 第 1-12 周 |

> ¥30,000 的总预算在第 8 周要付 ¥7,800 大货。此时再抽 ¥500-1,000 给唐装打样，虽然金额不大，但**精力比钱更紧**——媳妇一个人，洪洞线下单、手工制作、夜市摆摊、拍摄内容已经排满。

## 2. 启动条件（必须同时满足）

### 硬条件（缺一不可）

- [ ] **洪洞线回款 ≥ ¥3,000**（证明文创方向是对的）
- [ ] **手工线月出货 ≥ 20 件**（媳妇已掌握制作+出货的完整节奏）
- [ ] **媳妇已独立完成至少 10 个香囊**（工艺已上手，不依赖教程）
- [ ] **夜市/市集已验证香囊有人愿意买**（定价已被市场接受）

### 软条件（满足越多越好）

- [ ] 小红书账号已稳定更新 ≥ 8 周（有内容基础）
- [ ] 媳妇周末有至少半天可自由支配的时间（去逛街踩点）
- [ ] 已认识至少 1 个洪洞本地做服装生意的人（获取门店信息）

---

## 3. 启动时机判断

### 最早启动时间：第 16 周

为什么是第 16 周？

```
第 1-4 周   手工线启动 → 媳妇学做香薰石膏、夜市测试
第 5-8 周   洪洞线打样 → 穿插学做香囊（练手）
第 9-12 周  洪洞线到货 → 铺渠道、夜市验证香囊定价
第 13-16 周  数据积累 → 看回款、看出货量、看复购
第 16 周    判断节点 → 硬条件都满足 → 启动唐装线
```

### 如果第 16 周不满足条件

| 缺什么 | 怎么办 |
|---|---|
| 洪洞线回款不够 | 继续优化产品和渠道，延期到第 20 周 |
| 手工线出货不够 | 调整产品，先集中精力做好卖的那几款 |
| 香囊还没学会 | 回顾制作指南，降低复杂度（先做方形基础款） |
| 夜市香囊卖不动 | 调整定价或款式，在夜市验证通过再谈门店 |

> **核心原则：不满足硬条件就不启动唐装线。** 这不是放弃唐装合作，而是按正确顺序做事。

---

## 4. 不做什么（明确边界）

| 不做的事 | 为什么 |
|---|---|
| 不一启动就同时做香囊+发钗+压襟 | 精力撑不住，先从香囊单点突破 |
| 不一开始就谈联名定制 | 没有信任基础，谈联名是浪费口舌 |
| 不去临汾以外的城市找店 | 成本太高，先验证洪洞本地 |
| 不为了开门店渠道而降价 | 定价是产品定位的一部分，不为了铺货自降身价 |
| 不在没有样品的情况下去谈 | 空手去聊不出结果，必须带实物 |

## 5. 启动信号清单

以下信号出现任意 3 个，说明时机成熟：

- [ ] 夜市有人主动问"这个香囊可以在哪里买"
- [ ] 洪洞线产品在景区卖得不错，证明"本地文化牌"有效
- [ ] 媳妇说"这周不那么忙了，可以学点新的"
- [ ] 有人穿着唐装/旗袍来夜市，对香囊表现出兴趣
- [ ] 媳妇在日常生活中路过了一家唐装店，觉得可以聊

> 启动信号不是硬条件，但能帮你感受"时机到了没有"。

## 6. 总结

```
现在 → 先别想唐装
第 1-8 周 → 专注洪洞线 + 手工线，媳妇顺便学做香囊
第 9-12 周 → 夜市验证香囊，积累销售数据
第 13-16 周 → 看硬条件是否满足
第 16 周 → 满足 → 启动唐装线第一轮（1 家店 + 仅香囊）
          不满足 → 再等 4 周，继续打磨产品和渠道
```

> 唐装合作是一张好牌，但**好牌要等到对的时间打**。
