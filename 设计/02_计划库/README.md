## 2. 计划分区说明

### 01_区域计划
按地域/区域推进，比如：
- 广胜寺地域计划
- 洪洞地域文创计划

### 02_产品计划
按产品线推进，比如：
- 核心产品长期计划
- DIY体验计划
- 唐装配饰计划

### 03_合作计划
按合作对象/合作模式推进，比如：
- 唐装合作计划
- 门店合作计划
- 联名合作计划

### 04_长期规划
按时间尺度推进，比如：
- 年度规划
- 季度规划
- 产品路线图

### 05_专项计划
按事件/阶段推进，比如：
- 节日计划
- 上新计划
- 试点计划

---

## 3. 使用原则

- 计划只负责“怎么推进”，不重复产品正文
- 计划必须明确：目标、范围、阶段、版本引用、风险、清单
- 先验证可卖性，再决定是否放量或联名
- 计划名称尽量具体，避免空泛
- 新建计划先复制 `样板计划/`，再按项目改名填空
- 每个计划文件夹下保留：目标、范围、选型、版本引用、推进、风险、清单

---

## 4. 推进逻辑

1. 先定产品版本
2. 再设计划目标与范围
3. 然后做打样、试销和复盘
4. 达标后再放量或扩展合作
5. 不达标则回退、改版或暂停
