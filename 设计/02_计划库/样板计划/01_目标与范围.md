# 目标与范围

## 1. 目标
- 以洪洞地域文创纸品布艺为首轮样板
- 验证：产品能做出来 → 能卖出去 → 能复购
- 跑通后，将方法论复制到其他产品线

## 2. 范围
### 包含
- 产品选型（首批3款：冰箱贴、书签、明信片）
- 版本引用
- 推进安排（12周）
- 风险预案
- 首轮样稿与内容测试

### 不包含
- 手工高端线（独立运作，见产品库）
- DIY体验套装（远期方向，当前暂停）
- 唐装合作（第16周+再评估）

## 3. 成功标准
- 首批3款样品通过质检
- 第一批货到后30天，累计销售 ≥ ¥3,000
- 至少1款出现复购（同一渠道有人回购）
- 小红书内容测试：发布10条，粉丝增长 ≥ 100

## 4. 验收口径
- 有样品图、有报价单、有质检记录
- 第12周提交：总花费 / 总回款 / 哪款卖得好 / 下一步计划
- 不复制正文、不混淆版本

## 5. 约束条件

### 时间
- 启动时间：当前（2026年7月）
- 第1-4周：手工线启动 + 夜市出摊
- 第5-7周：洪洞线打样 + 设计外包
- 第8周：首批下单
- 第9-10周：等货到，包装准备
- 第11-12周：景区铺货 + 第二批下单

### 预算
- 首批洪洞线下单上限：¥8,300（含生活费）
- 设计外包：¥3,000（第5-6周分两期付）
- 机动储备：¥3,900（余额不得低于¥2,000）

### 人员
- 执行端：媳妇（本地），负责制作、摆摊、采购、客户对接
- 支持端：本人（北京远程），负责策划、设计对接、供应链、内容、财务决策
- 外协：设计师1名（外包，按稿件付费）

### 供应链
- 首选渠道：1688
- 打样必须3家比价
- 首次合作走平台交易，不私下付款
- 大货下单前必须确认产前样

## 6. 业务判断
- 先有可用版本，才值得开计划
- 先做样品和验证，再做扩展
- 每周复盘一次，遇到卡点立即决策，不拖
- 机动金余额 < ¥2,000：立即暂停非必要支出
- 任意单款连续3周周销 < 5件：停止补货
