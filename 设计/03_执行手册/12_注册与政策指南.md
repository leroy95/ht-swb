# 注册与政策实操指南

> **写给人看的注册手册**：不讲官话，只说该做什么、怎么操作。
> **适用场景**：山西洪洞县 · 手工文创工作室 · 个人创业

---

## 一、一句话结论

**前3个月不注册，全力卖货验证。月销稳超¥3,000再办个体工商户。月销破¥10万才需要考虑税务。**

## 三、注册全流程（山西洪洞线上办理）

### 3.1 注册前准备

| 项目 | 具体内容 | 哪里搞 |
|---|---|---|
| 经营者身份证 | 媳妇的身份证原件，正反面拍照 | 自有 |
| 经营场所证明 | 自住房：房产证照片；租房：租赁合同+房东房产证 | 自有 |
| 名称备选（2-3个） | 格式：洪洞县 + 字号 + 行业 + (个体工商户) | 自己起 |
| 手机号 | 实名认证的手机号 | 自有 |

**名称举例**：

| 示例名称 | 类型 |
|---|---|
| 洪洞县艺手工文创工作室(个体工商户) | 简洁型 |
| 洪洞县槐乡文创手作工作室(个体工商户) | 带地域特色 |
| 洪洞县XX工艺品店(个体工商户) | 店铺型 |

> "字号"就是品牌名，建议和以后小红书/夜市用的品牌名保持一致。

### 3.2 线上办理步骤

```
第1步：浏览器打开"山西省政务服务网"（sxzwfw.gov.cn）
      → 或下载"三晋通"APP
      → 实名注册/登录

第2步：搜索"个体工商户设立登记"
      → 点击进入，选择"在线办理"

第3步：填写基本信息
      ├─ 经营者：填媳妇的身份信息
      ├─ 经营场所：填洪洞家庭住址（与房产证一致）
      ├─ 名称：填备选名称，系统自动查重
      └─ 经营范围：见下方建议填写内容

第4步：上传材料照片
      ├─ 身份证正反面
      ├─ 经营场所证明（房产证关键页）
      └─ 其他（一般不需要）

第5步：提交审核
      → 等待1-3个工作日
      → 短信通知结果

第6步：下载电子营业执照
      → 微信小程序搜"电子营业执照"
      → 实名认证后下载
      → 效力等同纸质版
```

### 3.3 经营范围怎么填

**手工文创工作室建议填写**：

> **主营业务**：工艺美术品及礼仪用品制造（象牙及其制品除外）；工艺美术品及礼仪用品销售（象牙及其制品除外）；文艺创作

> **附加业务**（有就勾，没有不勾）：
> - 互联网销售（除销售需要许可的商品）
> - 组织文化艺术交流活动
> - 专业设计服务
> - 日用品销售

> **不需要**：食品经营（除非你卖食物）、出版物（除非你卖书籍）

**关键**：勾选"互联网销售"这一项，这样以后做电商、小红书开店都不用再改经营范围。

### 3.4 线下办理（备选）

如果线上搞不定（或就想跑一趟）：

```
地点：洪洞县市场监督管理局 / 行政服务中心
时间：工作日 9:00-12:00, 14:00-17:00
携带：身份证原件 + 复印件 + 房产证/租赁合同复印件
```

### 3.5 注册后必做事项

| 时间 | 做什么 | 不做的后果 |
|---|---|---|
| 领照后30天内 | 办理税务登记（线上可办） | 可能罚款 |
| 每年1.1-6.30 | 提交年度报告（几分钟的事） | 列入经营异常 |
| 每季度 | 税务申报（零收入也要报） | 罚款 |

> 税务登记和申报很简单，手机上就能做。真正复杂的税务问题是**月销破10万以后的事**，短期内不用操心。

## 四、税收政策全解

### 4.1 最核心政策：月销10万以内增值税全免

**政策来源**：财政部 税务总局公告2023年第1号（延续至2027年12月31日）

| 销售额档位 | 增值税 | 说明 |
|---|---|---|
| 月销 ≤ ¥100,000（季度 ≤ ¥300,000） | **0** | 开普通发票全额免税 |
| 月销 > ¥100,000 | **1%** | 仅对超出部分或不含税收入征收 |

> **这意味着前面至少半年到一年，你大概率一分钱增值税都不用交。**
> 夜市一晚上卖¥500、小红书一个月卖¥3,000——都远低于10万门槛。

### 4.2 个人所得税：核定征收

个体工商户不用交企业所得税（25%），只交个人所得税。而且"核定征收"方式下税率极低：

| 核定方式 | 税率 | 适合谁 |
|---|---|---|
| 定期定额 | 0%（月销过低于起征点） | 刚起步、月销几千 |
| 核定应税所得率 | 约1-2% | 月销有几千到几万 |
| 查账征收 | 5%-35%（阶梯） | 月销高、账目清晰 |

**本案适用**：前6-12个月大概率是"定期定额"或极低税率核定，实际个税趋近于零。

### 4.3 山西省叠加优惠（晋政发〔2023〕14号）

| 优惠 | 内容 | 适用期 |
|---|---|---|
| 个人所得税减半 | 年应纳税所得额 ≤ 100万 → 再减半 | 现行有效 |
| 六税两费减半 | 城建税、印花税、教育附加等全部减半 | 现行有效 |
| 经营保险免费 | 省财政出钱，个体工商户免费享受经营中断/财产损失/第三者责任险 | 2023.9起3年 |
| 首次轻微违法不罚 | 包容审慎监管 | 现行有效 |

### 4.4 综合算税（仿真案）

假设你是个体工商户，以下是不同月销的实际税收：

#### 场景A：月销 ¥3,000（起步阶段）

| 税种 | 金额 | 说明 |
|---|---|---|
| 增值税 | ¥0 | 月销≤10万免税 |
| 附加税 | ¥0 | 增值税为零则无附加 |
| 个人所得税 | ¥0 | 定期定额、低于起征点 |
| 六税两费 | ¥0 | 无应纳税额 |
| **到手** | **¥3,000** | **纯利润** |

#### 场景B：月销 ¥8,000（稳定阶段）

| 税种 | 金额 | 说明 |
|---|---|---|
| 增值税 | ¥0 | 月销≤10万免税 |
| 附加税 | ¥0 | — |
| 个人所得税 | ≈¥80 | 核定约1% |
| 山西个税减半 | -¥40 | — |
| **实际缴税** | **≈¥40** | **税率0.5%** |
| **到手** | **≈¥7,960** | |

#### 场景C：月销 ¥50,000（爆发阶段）

| 税种 | 金额 | 说明 |
|---|---|---|
| 增值税 | ¥500 | 1%（小规模） |
| 附加税 | ¥30 | 增值税的6%，山西减半后≈3% |
| 个人所得税 | ≈¥750 | 核定约1.5% |
| **实际缴税** | **≈¥1,280** | **税率2.6%** |
| **到手** | **≈¥48,720** | |

> 看场景C：**月销5万，缴税不到¥1,300。** 这就是个体工商户的政策红利。

## 五、分阶段行动清单

### 阶段一：前3个月（纯验证期）

| 事项 | 做不做 | 说明 |
|---|---|---|
| 注册工商 | ❌ 不注册 | 全力卖货验证 |
| 收款方式 | 微信/支付宝个人码 | 够用 |
| 记账 | ✅ 自己做 | 每周六记账，Excel就行 |
| 税务 | ❌ 无关 | 没注册就不用管 |

### 阶段二：月销¥3,000-5,000（起量期）

| 事项 | 做不做 | 说明 |
|---|---|---|
| 注册工商 | ✅ 注册 | 线上办理，3天出照 |
| 税务登记 | ✅ 线上登记 | 30天内完成 |
| 开发票 | 🔶 看需求 | 有客户要就开电子发票 |
| 记账 | ✅ 继续自己记 | 保持每周记账习惯 |
| 税负 | ≈0 | 月销几千几乎不交税 |

### 阶段三：月销¥5,000-30,000（稳定期）

| 事项 | 做不做 | 说明 |
|---|---|---|
| 季度申报 | ✅ 必须做 | 手机/电脑操作，10分钟 |
| 年度报告 | ✅ 1-6月提交 | 几分钟搞定 |
| 记账 | ✅ 规范化 | 考虑记账APP |

## 六、常见问题 FAQ

**Q：不注册可以开拼多多/闲鱼店吗？**

A：闲鱼个人店不需要营业执照。拼多多个人店部分品类也不需要。但企业店、旗舰店需要执照。建议先从闲鱼+个人店开始。

**Q：不注册可以在小红书卖东西吗？**

A：小红书开店需要营业执照。但前3个月建议先做内容涨粉，不急着开店。粉丝有了、产品验证了，注册+开店一步到位。

**Q：注册个体工商户后，是不是必须开对公账户？**

A：不是。个体工商户可以直接用**经营者个人银行卡**收款，不需要开对公账户。这是重大便利。

**Q：注册后没人买也要报税吗？**

A：要。但"零申报"很简单——在税务APP上点几下就完成了。不申报会有罚款。

**Q：家庭住址能注册吗？会不会有人来检查？**

A：能。2025年新规明确放宽了经营场所登记条件，住宅可以作为经营场所。一般不会有人来家里检查，尤其你是手工制作、不对外营业的工作室。

**Q：注册后不想做了怎么办？**

A：注销很简单。线上提交注销申请，成立满180天后可以办理。没有负债的话1-2周搞定。注意注销前要清税。

**Q：会不会因为不注册被处罚？**

A：个人零星小额交易（非持续性、非规模化）不属于无照经营的查处范围。初期个人接单、夜市摆摊、微信卖货，不在强制注册范围内。
