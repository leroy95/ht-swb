# 🏠 个人工作室运营手册（V1.0.0）

> **适用人**：执行端（媳妇），每天用这份手册知道怎么运转
> **支持端**：远程（北京）负责策划、设计、供应链、内容、财务决策
> **原则**：分工清楚 · 节奏固定 · 遇到问题直接说

---

## 1. 工作室是什么

不是公司，不是门店，就是在家做的小生意。

- 生产在家：做手工、组装包装、备货
- 销售在外：夜市摆摊、景区铺货、线上发货
- 管理在线：微信沟通 + 文档记录 + 每周视频同步

---

## 2. 执行端每日工作节奏

### 工作日（3-5小时）

```
上午 09:00-11:00：手工制作时间（最核心，每天必做）
  → 香薰石膏 / 香囊 / 蜡烛，按当周订单量生产
  → 制作时顺手拍1-2张过程照片备用

下午 14:00-16:00：运营事务
  → 淘宝/1688接收快递、检查材料
  → 回复客户微信/私信
  → 处理当日订单打包发货（如有）

晚上 20:00：每日同步（5分钟）
  → 发一条语音给支持端：今天做了什么、有没有卡住的问题
  → 支持端当晚回复决策或建议
```

### 周末节奏

```
周六：夜市出摊（带手工品 + 洪洞文创）
  → 出摊前2小时准备货品、摆台道具、零钱
  → 出摊时拍1-2条短视频素材（顾客看产品的反应）
  → 收摊后当天记录：今日销售金额 / 卖得最好的产品 / 客户说了什么

周日：
  → 上午整理本周成品、检查库存
  → 晚上视频复盘30分钟（见下方"每周视频复盘"）
  → 记本周账（参考启动资金使用明细的记账模板）
```

---

## 3. 执行端每周必做清单

每周日晚上，确认以下5件事都做了：

- [ ] 本周账单记录完毕
- [ ] 本周成品照片发给支持端看
- [ ] 本周销售记录（夜市+微信+其他）
- [ ] 材料库存盘点（下周需要补什么）
- [ ] 有没有卡住的问题告知支持端

---

## 4. 每周视频复盘（30分钟）

每周日晚20:00-20:30，固定30分钟。

**节奏**：

| 时段 | 内容 |
|---|---|
| 0-10分钟 | 账单：本周花了多少、收了多少、余额是多少 |
| 10-20分钟 | 进展：打样/材料/订单的最新状态 |
| 20-30分钟 | 下周计划：明确3件最重要的事 |

**不需要讲**：不需要汇报每一步细节，只说"做了什么、结果是什么、有没有卡住"。

## 5. 支持端远程工作方式

### 远程能做的事

- 帮媳妇在1688选款、看评价、比价
- 与设计外包远程沟通，发文件、确认稿件
- 写小红书文案，发给媳妇配图发布
- 协助处理发货单、打单工具配置
- 看周报数据，决策是否追加下单

### 做不到的事（需要媳妇配合）

- 实物拍照（需要实物在身边）
- 现场定价测试（需要面对顾客）
- 材料质量判断（需要摸过样品才知道）
- 夜市摆摊（人必须在现场）

### 远程决策规则

**一般情况**：媳妇自己判断，事后同步即可（省时间）

**必须确认再动手**：
- 单笔支出超过¥500
- 接到景区/门店合作邀请
- 准备改变某款产品的设计或定价
- 某款产品连续两周卖不动，考虑停产

## 6. 个人工作室成本控制要点

### 不花的钱

```
✗ 不租工作室（在家做）
✗ 不请员工（第1年媳妇一个人跑）
✗ 不买设备（手机拍照，家用烤箱，家用工具）
✗ 不办公司（个体户在月销超¥5,000后再考虑）
✗ 不开直播（第1年不搞直播，先把产品做稳）
```

### 省下来的钱怎么花

```
✓ 每月固定留100-200元给媳妇买手工材料做练习（提升手艺）
✓ 节假日前提前2周备货（成本低时多备一点）
✓ 卖得好的SKU优先补货（不要平均分配资金）
```

## 7. 关键预警信号

以下情况发生时，立即微信通知支持端，不要自己扛：

| 信号 | 含义 |
|---|---|
| 账户余额 < ¥5,000 | 资金警报，暂停非必要支出 |
| 连续两次夜市零销售 | 产品或定价有问题，需要复盘 |
| 工厂打样超过2周无进展 | 催一次，再无回应换供应商 |
| 某款产品连续3周销量< 5件 | 停止补货，考虑清仓 |
| 媳妇连续感到很累 | 立刻减负，不是坚持，是调整 |

## 8. 工作室阶段发展

### 第1阶段（月销 < ¥3,000）
- 身份：个人，无需注册
- 收款：微信个人收款
- 记账：手动记录即可
- 策略：先活下去，不要追求完美

### 第2阶段（月销 ¥3,000 - ¥10,000）
- 考虑注册个体工商户（线上办理，¥0费用）
- 开一个专用银行账户管理资金
- 考虑淘宝/拼多多开店（可提高信任度）

### 第3阶段（月销 > ¥10,000）
- 考虑请1个兼职帮手（每周2-3天，计件工资）
- 引入更正规的库存管理
- 景区/门店合作正式化（补货协议、结款周期）

## 9. 媳妇的核心优势

这件事特别适合媳妇来做，因为：

- 在本地，懂洪洞文化，接地气
- 有时间，可以把每天3-5小时用得很扎实
- 夜市摆摊，本地人比外地人更容易和客户建立信任
- 手工制作，做出来的东西带有个人温度，这是工厂做不到的

支持端（北京）负责把"方向、资源、工具"送到她手边，她负责把事情踏踏实实做起来。这是最合理的分工。
