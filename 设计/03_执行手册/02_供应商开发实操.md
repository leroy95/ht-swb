### 第2步：筛选靠谱工厂

```
在搜索结果中筛选：
  ✅ 有"诚信通"标识（入驻1688 3年以上）
  ✅ 有"深度验厂"标识
  ✅ 店铺评分 ≥ 4.7
  ✅ 最近30天有成交记录
  ✅ 有类似产品的成交记录（看评价区的图）
  
  ❌ 刚开的新店（< 6个月）
  ❌ 评分 < 4.5
  ❌ 没有任何评价和成交记录
  ❌ 只有产品图没有实物图
```

### 第3步：发询价（用模板）

#### 询价模板（直接复制用）

```
你好，我们是一个文创品牌，想做一批定制产品，请报价：

产品：锌合金珐琅冰箱贴
数量：首批200枚（确认品质后会追加500-1000枚）
尺寸：约4cm × 5cm
工艺：锌合金压铸 + 珐琅填色（7色）
图案：我们自己提供设计稿（AI/CDR矢量文件）
包装要求：每个单独装透明袋 + 背卡

请提供：
1. 单价（含模具费吗？模具费单独报）
2. 打样费（出样品多少钱？大货是否抵扣？）
3. 交期（打样几天？大货几天？）
4. 起订量（最低做多少个？）
5. 包装选项（背卡/透明袋你们提供吗？加多少钱？）

谢谢！
```

#### 必问的5个问题

| 问题 | 为什么重要 | 好的回答 | 不好的回答 |
|------|----------|---------|----------|
| 模具费多少？ | 金属产品开模费可能¥500-2000 | 200个可免 | 模具费另加¥800 |
| 打样费多少？大货抵扣吗？ | 打样¥100-300很正常 | 打样¥200，大货满¥2000退 | 打样费不退 |
| 起订量多少？ | 确认不会超量 | 200个起 | 1000个起 |
| 交期多少？ | 排产要预留时间 | 打样7天+大货15天 | 不确定，看排期 |
| 色差怎么控制？ | 珐琅颜色容易偏 | 寄色板确认，大货对色板 | 差不多就行 |

### 第4步：比3家

```
至少问3家工厂，填下面这个表：

| 工厂名 | 单价 | 模具费 | 打样费 | 起订量 | 交期 | 1688评分 | 是否寄样 |
|--------|:---:|:-----:|:-----:|:-----:|:---:|:------:|:------:|
| A厂 | ¥4.5 | ¥0(200免) | ¥200(大货退) | 200 | 22天 | 4.8 | 是 |
| B厂 | ¥3.8 | ¥600 | ¥150(不退) | 500 | 18天 | 4.6 | 否 |
| C厂 | ¥5.2 | ¥0(100免) | 免费 | 100 | 25天 | 4.9 | 是 |

选C厂（虽然单价高，但起订量低+免费打样+评分高）
→ 首批省模具费+降低库存风险
```

## 二、下单流程（标准操作）

### 选择逻辑
- 优先选能先打样、再小批、再放量的工厂
- 优先选报价透明、起订量可控、愿意寄样的供应商
- 优先选能和我们一起把包装、配件、交期一起解决的工厂
- 不是单价最低就一定选，稳定交付和可复购更重要

### 结款方式谈判

```
理想的付款节奏：
  30%定金（下单时付）→ 工厂开始做 → 
  寄样品确认（不额外收费）→ 
  70%尾款（发货前付）→ 工厂发货

能谈到的：
  小批量（200-500个）→ 通常要求全款付清
  中批量（500-2000个）→ 可以谈30/70
  大货量（以后）→ 可以谈月结

首次合作建议：接受全款（¥2,000-5,000的单，风险可控）
```

### 验货标准（收货时对照）

```
打开箱子第一件事：抽检10%

金属冰箱贴：
  □ 颜色与确认的色板一致（偏差不超过2个色阶）
  □ 珐琅填色没有溢出边界
  □ 背面光滑、没有毛刺
  □ 磁铁吸力足够（贴冰箱不会自己滑下来）
  □ 没有划痕、磕碰

明信片/贴纸：
  □ 颜色与设计稿一致
  □ 没有偏色、套印不准
  □ 纸张克重达标（手摸有厚度）
  □ 裁切整齐、没有毛边

丝绸/帆布袋：
  □ 图案与设计稿一致
  □ 没有色差（尤其肤色和红色）
  □ 面料手感对（真丝 vs 仿真丝要区分）
  □ 缝线整齐、无线头

不合格处理：
  轻微瑕疵 < 5% → 正常，自己挑出来
  瑕疵 5-10% → 联系工厂退款/补发差额
  瑕疵 > 10% → 整批拒收 → 要求重做或全额退款
```

## 三、成本优化技巧

### 省钱7招

```
① 合并品类到同一个厂
  冰箱贴+书签+徽章 → 都给东莞1家金属厂做
  → 总金额大 → 议价空间大 → 运费只付一次

② 共用模具
  同形状不同颜色 → 共用1套模具，只换珐琅色 → 省开模费

③ 错峰下单
  不要春节前1个月下单（工厂赶工涨价）
  1-2月/8-9月是工厂淡季 → 好谈价

④ 包装自己买
  工厂提供的包装比1688贵30-50%
  → 问厂家要裸装价
  → 包装自己在1688买（背卡¥0.3-0.5/张，透明袋¥0.1/个）

⑤ 首批只要最低起订量
  不要"200个够吗？要不要500个？（单价便宜¥0.5）"
  → 多出来的300个卖不掉 = ¥1,350亏掉
  → ¥0.5差价 × 200个 = 省¥100 → 不值得

⑥ 设计稿提前做好
  工厂说"我们帮你设计" → 加¥500-1000设计费
  自己出好AI/CDR矢量文件 → 省掉设计费

⑦ 问清运费
  工厂报价可能是"不含运费"
  → 200枚冰箱贴从东莞到洪洞，快递约¥30-50
  → 比工厂报价时确认一下
```

## 四、供应商开发时间表

| 第几周 | 动作 | 产出 |
|:---:|------|------|
| 第5周 | 1688搜索+联系各品类工厂+发询价 | 每品类联系5-8家 |
| 第6周 | 收报价+比价+选3家/品类 | 确定15个供应商短名单 |
| 第6-7周 | 发设计稿+要求打样 | 每品类1-2家打样 |
| 第7-8周 | 收样品+验货+确定1家/品类 | 确定最终供应商 |
| 第8周 | 下单+付定金 | 首批生产启动 |
| 第10-11周 | 收货+验货 | 15款产品入库 |

---

> **重要提醒**：不要急着下单。打样至少做一轮（7-10天），样品确认了再量产。
> 样品不行→换一家打样→不要将就（将就的样品=将就的大货=卖不动的库存）
