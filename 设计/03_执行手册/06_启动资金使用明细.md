## 四、省钱原则

```
① 能不花的坚决不花
  → 自己拍产品图 ≠ 请摄影师
  → 自己摆摊 ≠ 开门店
  → 手机拍视频 ≠ 买相机

② 花小钱试错，不多投
  → 首批只下单200件/款，不多囤
  → 打样费¥100-300，做错了就换一家
  → 夜市场地¥50试1周，效果好才续

③ 用收入滚动发展
  → 第一批货卖出去的钱 → 存在余额里
  → 第二批下单用第一批回款+余额
  → 不借钱、不刷信用卡、不找家里人再要

④ 生活开销压缩到最低
  → 前3个月生活费 ¥3,000（月均¥1,000）
  → 吃住在家/低成本生活方式
  → 第4个月如果有收入，适当提高
```
