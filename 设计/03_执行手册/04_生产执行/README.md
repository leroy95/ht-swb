# 手工生产体系

> **定位**：生产、培训、品控与结算的专题入口
> **说明**：可继续独立使用，也可作为执行手册的生产补充模块

---

## 1. 这个模块负责什么

- 适合在家生产的品类筛选
- 培训、上岗、排产、质检
- 计件与结算
- 节前排产与风险控制

---

## 2. 核心业务逻辑

- 先看产品是否适合手工拆分，再决定是否进入生产体系
- 先低风险件，再高客单件
- 先样品确认，再试产，再放量
- 先通过品控，再进入结算与交付
- 任何不稳定因素，优先回到小批次和可追溯状态

## 4. 使用原则

1. 先看指南，再落到具体 SKU
2. 先低风险件，再高客单件
3. 先通过品控，再放量
4. 与核心产品线共用选品逻辑，与执行手册共用操作逻辑
5. 结算前必须确认数量、质量和批次记录
