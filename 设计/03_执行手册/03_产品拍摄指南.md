# 📸 产品拍摄指南（手机版）

> **核心问题**：我不会拍照，没有专业设备，怎么拍出能卖¥200+的产品图？
> **一句话**：光线 > 背景 > 构图 > 手机型号。用对光，¥2000的手机也能出片。

---

## 一、拍摄准备（¥50预算）

### 必备工具

| 工具 | 推荐 | 预算 | 替代方案 |
|------|------|:---:|------|
| 手机 | 任何支持"人像模式"的手机 | ¥0 | 你现在用的就行 |
| 背景布 | 米色亚麻布 1m×1.5m | ¥15 | 旧的米色床单/窗帘 |

> 总预算：¥50。除背景布和底座，其他都可以不花钱。

## 二、光线（最重要的！拍不好都是光线问题）

### 黄金法则

```
❌ 不要用的光：
  → 室内顶灯（又黄又暗）
  → 手机闪光灯（惨白+反光）
  → 正午室外直射光（太硬、影子太重）

✅ 最佳光源：
  → 窗边自然光（上午9-11点，下午2-4点）
  → 阴天室外（天然柔光箱）
  → 靠窗1-2米处
```

### 光线布局

```
              窗户（自然光）
                  ↓↓↓
         ┌────────────────┐
         │                │
         │  [产品在这里]   │
         │                │
         │     (你)       │
         └────────────────┘
              [白泡沫板]
           （放在产品和窗户对面，
            把光反射回产品暗面）
```

> 白泡沫板放在产品暗面 → 把窗户光反射回产品 → 暗面不会全黑 → 质感翻倍

## 三、6种必拍角度

### 每款产品至少拍这6张

| # | 类型 | 怎么拍 | 用处 |
|:--:|------|------|------|
| 1 | **全景俯拍** | 产品平放+背景布，手机在正上方平行拍摄 | 小红书封面、淘宝主图 |
| 2 | **45°斜拍** | 手机拿高约45°，拍产品的侧面和厚度 | 展示立体感 |
| 3 | **细节特写** | 凑近拍产品的局部（绣线/颜色过渡/材质纹理） | 让人看清"手工质感" |
| 4 | **手持独照** | 一只手拿着产品，背景虚化/自然场景 | 展示实际大小 |
| 5 | **原材料合照** | 产品旁边放上制作它的原材料和工具 | "这是手工做的"的视觉证明 |
| 6 | **场景使用** | 香囊挂在包上、丝巾围在领口、冰箱贴贴在冰箱上 | 让客户想象自己用上的样子 |

### 冰箱贴6张实例

```
图1：4枚冰箱贴排列在木砧板上，从正上方俯拍
图2：45°斜拍，展示珐琅填色的厚度和光泽
图3：特写斗拱那枚——木纹质感+金色线条的细节
图4：一只手拿着飞虹塔的那枚贴在铁门上（背景虚化）
图5：冰箱贴旁边放设计稿+色卡+未完成的半成品
图6：在广胜寺实景，飞虹塔前手拿冰箱贴合影（景区场景）
```

## 四、手机设置

### 拍摄前检查

```
iPhone：
  设置 → 相机 → 格式 → 选"兼容性最佳"
  拍摄时 → 关闭"实况"（Live Photo）
  人像模式 → 选"自然光"
  
  不要用：滤镜、AI增强、人像模式的"舞台灯光"

安卓：
  相机设置 → 关闭AI场景识别 / AI增强
  关闭美颜（会把产品纹理磨没）
  关闭HDR（颜色会失真）
  
  不要用：任何自带滤镜

所有手机通用：
  ✅ 用原生相机（不要用美颜相机/轻颜等App）
  ✅ 对焦在产品最想突出的位置
  ✅ 曝光稍微降0.3-0.5（让画面更"高级"）
  ✅ 拍完用手机自带编辑微微调整亮度+对比度
```

## 五、背景与色彩搭配

### 不同产品的推荐背景

| 产品 | 推荐背景色 | 推荐底座 | 避雷 |
|------|---------|---------|------|
| 金属冰箱贴（金色/彩色珐琅） | 米白亚麻/深灰水泥 | 木砧板/旧书 | ❌ 不要用彩色底（抢戏） |
| 香囊（布艺） | 米色亚麻/牛皮纸 | 旧木盒/双手捧着 | ❌ 不要花底（缝线看不清） |
| 蜡烛（白色蜡体） | 深色木板/暖灰水泥 | 旧铜盘/石头 | ❌ 不要白底（融到背景里） |
| 丝巾（彩色图案） | 白色/米色纯色底 | 平铺 or 折叠垂坠 | ❌ 不要花底 |
| 明信片/贴纸 | 深色木纹/牛皮纸 | 散开排列/扇形展开 | ❌ 不要白底（对比不够） |

## 六、后期处理（3分钟快速版）

### 用手机自带编辑就够了

```
步骤1：裁剪 → 比例选"1:1"（小红书/朋友圈）或"4:5"（竖版最合适）
步骤2：亮度 +5~10（让产品亮一点）
步骤3：对比度 +3~8（让线条更清晰）
步骤4：饱和度 -2~5（稍微降一点，颜色更"高级"）
步骤5：锐度 +3~5（看清手工细节）
步骤6：（可选）色温微调：暖色产品+2，冷色产品-2

禁忌：
  ❌ 不要猛加滤镜（产品颜色失真=退货）
  ❌ 不要加文字水印（土）
  ❌ 不要加边框（占画面）
```

## 七、拍摄清单（每款产品打勾）

```
产品：_______________  拍摄日期：_______________

□ 第1张：全景俯拍（纯背景+产品居中）
□ 第2张：45°斜拍（展示立体感）
□ 第3张：细节特写（纹路/材质/颜色过渡）
□ 第4张：手持独照（展示大小，背景虚化）
□ 第5张：原材料合照（设计稿/工具/材料在旁边）
□ 第6张：场景使用（挂起来/戴起来/用起来）
□ 第7张：（可选）制作过程（手在做产品的瞬间）
□ 第8张：（可选）包装展示（产品+包装盒一起拍）

检查：
□ 光线：窗边自然光，暗面有泡沫板反光
□ 背景：颜色搭配好，没有杂物
□ 焦点：对在产品最想突出的位置
□ 曝光：稍微偏暗（-0.3），画面舒服
□ 构图：1:1 或 4:5，产品占画面60-70%
```
