## 四、核心技术点

### 4.1 法式钩针刺绣（Luneville Embroidery）
- **核心工具**：Luneville 钩针（带木柄的微型钩针）
- **工作方式**：绣布架在绣绷上，左手在布面上送珠，右手持钩针从反面穿刺，钩住米珠/亮片后回拉
- **关键难点**：手眼协调（反面操作盲钩）、送珠节奏、线迹松紧控制

### 4.2 必须掌握的针法
| 针法 | 用途 |
|------|------|
| 链条绣(Chain stitch) | 轮廓线、底纹 |
| 粒粒绣(Bead embroidery) | 逐粒缝珠 |
| 钩针连珠绣(Tambour beading) | 快速串珠走线 |
| 立体垫绣(Padding stitch) | 做出浮雕般凸起 |
| 金线盘绣(Goldwork) | 贵气华丽质感 |

### 4.3 设计能力要求
- 配色审美——东方色系（青绿、汝窑、敦煌色板）
- 构图能力——适合小尺寸的精致构图
- 材质搭配——米珠/亮片/绣线/金属配件的搭配逻辑

### 4.4 学习路径
```
第1–2周：工具使用 + 基础链条绣 + 逐粒缝珠
第3–4周：钩针连珠绣 + 简单图案制作
第5–6周：垫绣 + 金线盘绣 + 完整体作品
第7–8周：独立设计 + 形成个人风格
```

## 六、客户常见问题（话术参考）

**Q：这是绣在什么上面的？会不会不结实？**
> 用的是真丝欧根纱，轻薄但韧性很强，高定工坊同款底布。绣完后会固定在硬挺背衬上，再装配件，日常佩戴完全没问题。

**Q：米珠会不会掉？**
> 我们用的御幸米珠是世界顶级品质，走线是法式双锁链结构——即使某一处断线，也不会连续掉珠。而且提供终身免费修补。

**Q：和市面上的珍珠胸针有什么区别？**
> 市面大多是机器热压或简单串珠，我们是法式钩针珠绣——高定工坊的工艺标准，一件胸针手工耗时 2–4 小时，细节肉眼可见的差距。
