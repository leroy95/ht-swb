## 四、核心技术点

### 4.1 树脂配比与温度（最关键！）
- **A:B 配比**：严格按说明书（通常 3:1 重量比），偏差大则不固化
- **搅拌**：同一方向慢速搅拌 2–3 分钟，减少气泡
- **温度**：工作温度 20–25°C 最佳，温度低固化慢/不固化，温度高固化太快产生气泡
- **消泡**：搅拌后静置 5 分钟 + 热风枪吹表面气泡

### 4.2 分层灌注技法
这是做出"景深感"的核心技术：

```
第1层(底层) → 灌注 2–3mm → 固化 12h → 放入中景花材
第2层(中景) → 灌注覆盖 → 固化 12h → 放入前景花材
第3层(前景) → 灌注覆盖 → 固化 12h → 置入最上层点缀
第4层(封层) → 最终灌注 → 固化 24h
```

- **每层厚度**：3–5mm 最佳，太厚发热严重会开裂
- **固化时间**：每层 8–12 小时（薄层更快）

### 4.3 花材处理
- **压制**：鲜花夹入压花器 → 放置 3–7 天 → 取出干燥花材
- **保色**：部分花材（如红色/紫色系）压制后会褪色，需要选对花材品种
- **最佳花材**：绣球（颜色保持好）、满天星、蕨类叶、飞燕草、三色堇
- **入树脂前**：花材必须彻底干燥，否则在树脂里会腐烂变黄

### 4.4 打磨抛光
``` 
固化后表面可能有不平整、边缘毛刺 →
400目(粗磨) → 800目 → 1500目 → 3000目 → 5000目(细磨) →
涂抛光膏 → 布轮抛光 → 镜面效果
```

### 4.5 学习路径
```
第1周：配比练习 + 基础小件（杯垫、钥匙扣）
第2周：分层技法 + 花材摆放构图
第3周：打磨抛光 + 大件制作（托盘）
第4周：复杂构图 + 多物件组合
```

## 六、客户常见问题（话术参考）

**Q：树脂会不会变黄？**
> 我们用的高透环氧树脂添加了 UV 抗黄变剂，正常室内使用 3–5 年内基本看不出变化。避免长时间阳光直射可以保持更久。树脂黄变是所有树脂的物理特性，就像纸张会泛黄一样——但我们选的胶水是目前市面上抗黄变最好的。

**Q：干花在里面会不会腐烂/褪色？**
> 花材在入树脂前经过严格干燥处理（含水率 < 3%），完全干燥的花材在密封树脂里不会腐烂。褪色方面，我们优选保色性好的花材品种（如绣球、满天星），颜色稳定。

**Q：碎了怎么办？**
> 环氧树脂固化后硬度很高，正常使用摔不碎。但如果用锤子砸——那确实会碎。正常使用场景完全没问题。

**Q：可以定制婚礼手捧花吗？**
> 可以，这是我们最受欢迎的定制服务。客户在婚礼后将手捧花寄给我们 → 我们做干燥处理 → 封存入树脂 → 制成装饰画或摆件。全程约需 3–4 周。建议提前预约，婚礼季排单紧张。
