## 四、核心技术点

### 4.1 微钩针法体系
| 针法 | 英文 | 用途 |
|------|------|------|
| 锁针 | Chain (ch) | 茎、藤蔓 |
| 短针 | Single crochet (sc) | 小叶片 |
| 长针 | Double crochet (dc) | 花瓣主体 |
| 长长针 | Triple crochet (tr) | 细长花瓣 |
| 狗牙针 | Picot | 花瓣边缘锯齿 |
| 环起始 | Magic ring | 圆形花朵起始 |

### 4.2 微型化技巧
- **线材选择**：#80 线最细效果最好但最难操作，入门从 #40 开始
- **钩针握法**：不同于普通钩编，微钩需要更轻柔的力道控制
- **照明与放大**：必须配备 3–5 倍带灯放大镜，肉眼几乎不可操作
- **张力一致性**：微型钩编对手劲均匀度要求极高，松紧不一会导致花瓣大小不一

### 4.3 定型技术
- 钩编完成后的花朵/叶片是软的
- 需要浸泡定型液 → 塑形（用保鲜膜包裹在模具上固定形态） → 自然晾干
- 定型后硬挺如纸花，佩戴不变形

### 4.4 学习路径
```
第1–3周：普通钩编基础（如果零基础）
第4–6周：#40线 + 0.6mm钩针 练习基本花型（雏菊、樱花、五瓣花）
第7–9周：#60线 + 0.5mm钩针 进阶花型（玫瑰、铃兰、绣球）
第10–12周：#80线 + 配色设计 + 组合成首饰
```

## 六、客户常见问题（话术参考）

**Q：这么细的线，会不会很容易断/坏？**
> 定型后硬挺度很好，日常佩戴完全没问题。而且蕾丝线本身是优质长绒棉，强度比看起来高得多。当然它毕竟是手工艺术品，不是工业塑料——需要像对待珠宝一样温柔对待。

**Q：能不能机洗/碰水？**
> 不能。手工微钩首饰像所有珠宝一样，需要避免碰水、避免大力拉扯。日常佩戴后放回首饰盒即可。

**Q：为什么这么贵，这么小？**
> 正因为小，才贵。微型钩编比普通钩编难 3 倍以上——#80 线比头发丝还细，一朵拇指大的铃兰花要做 40 分钟。这不是流水线产品，是显微镜下的手工艺。
