## 一、为什么唐装 + 手工配饰是最好组合？

### 天然互补

```
唐装/旗袍店痛点：
  ❌ 只卖衣服 → 客单价 ¥500-1500 → 毛利 40-50%
  ❌ 客户买完衣服还要自己配饰 → 配不好整体效果打折
  ❌ 老客维护难 → 一件唐装穿几年，复购周期太长

手工文创的解决方案：
  ✅ 压襟/发簪/香囊 → 配饰客单价 ¥128-798 → 毛利 60-80%
  ✅ 唐装+配搭一起卖 → 客单价翻 50%+（¥1500 → ¥2200+）
  ✅ 配饰是消耗品/搭配品 → 老客可以持续买新配饰
  ✅ 配饰是手工做的 → 不是工业品，有"独一无二"感
```

## 三、🥇 核心品类：压襟（主推爆款）

### 什么是压襟？

```
压襟 = 古代女子挂在衣襟上的配饰

来历：
  传统旗装/唐装衣襟较长 → 走路时衣襟容易飘起
  → 在衣襟上挂一串有重量的饰品 → 压住衣襟 → 称为"压襟"
  → 后逐渐演变为女性衣襟上的装饰品

现代意义：
  穿旗袍/唐装时，压襟是胸前第一件被注意到的配饰
  → 比项链更显眼 → 比胸针更有文化感
  → 是唐装搭配的"灵魂配饰"
```
