## 四、核心技术点

### 4.1 植物染料提取
| 植物 | 颜色 | 提取方法 |
|------|:---:|------|
| 靛蓝 | 蓝 | 发酵还原法——最复杂，需建靛泥缸 |
| 苏木 | 红/粉/紫 | 水煮提取 + 明矾/皂矾调色 |
| 栀子 | 黄 | 水煮提取，最简单 |
| 五倍子 | 灰/黑 | 水煮 + 皂矾媒染 |
| 紫草 | 紫 | 酒精浸泡萃取 |
| 洋葱皮 | 棕黄 | 水煮（家居废料利用） |

### 4.2 扎染技法（至少掌握 3 种）
| 技法 | 效果 | 难度 |
|------|------|:--:|
| 绑扎法 | 圆点/条纹 | ⭐ |
| 夹染法(Itajime) | 几何图形 | ⭐⭐ |
| 缝扎法 | 精确图案 | ⭐⭐⭐ |
| 卷染法(Arashi) | 斜纹纹理 | ⭐⭐ |
| 蜡染(Batik) | 精细图案 | ⭐⭐⭐⭐ |

### 4.3 媒染与固色（决定品质的关键）
- **前媒染**：先媒染再染色——颜色更深更均匀
- **后媒染**：先染色再媒染——颜色变化更多
- **同浴媒染**：染料+媒染剂一起——简化流程
- **固色**：染后反复水洗 + 醋浸泡固色 → 测试色牢度

### 4.4 学习路径
```
第1–2周：认识材料 + 栀子/苏木等简单水煮染色
第3–4周：学习绑扎/夹染/卷染 + 媒染实验
第5–6周：靛蓝建缸 + 蜡染入门
第7–8周：综合技法 + 系列创作
```

## 六、客户常见问题（话术参考）

**Q：植物染会不会褪色？**
> 做好媒染和固色处理后，日常佩戴不掉色。但植物染的特性是随着时间推移会自然氧化，颜色会产生微妙的变化——这不是褪色，是"生长"。很多客户反而期待这种变化。

**Q：和化学染丝巾有什么区别？**
> ① 植物染颜色温润不刺眼，化学染鲜艳但缺乏层次；② 植物染每一条都独一无二，化学染批量一致；③ 植物染环保亲肤，化学染有化学残留风险。

**Q：为什么这么贵？**
> 一条植物染丝巾从提取染料→扎花→染色→媒染→拆线→固色→洗晾→熨烫，纯手工需要 1–3 天。而工厂化学染丝巾半小时一条。时间是它的成本。
