## 一、IP 深度解读

### 飞虹塔速写

```
建造年代：明嘉靖六年（1527年）重建，塔基可追溯至唐代
建筑形制：八角十三层楼阁式砖塔，通高 47.31 米
核心特征：
  ├─ 全身镶嵌 7 色琉璃砖雕，阳光下彩虹般绚烂——"飞虹"之名由此而来
  ├─ 砖雕内容：佛龛、菩萨、飞天、力士、瑞兽、花卉、藻井纹样
  ├─ 中国现存唯一一座留有工匠题款的琉璃塔
  ├─ 曾在 1930s 被梁思成、林徽因测绘，称其为"中国琉璃塔的代表作"
  └─ 86版《西游记》唐僧扫塔取景地
```

#### 制作流程

```
步骤1：原型制作
  用硅胶翻模泥从3D打印原型上翻出模具（1个模具可翻50–80次）

步骤2：石膏灌注
  高强石膏粉+水调浆 → 灌入模具 → 震动消泡 → 凝固30分钟 → 脱模

步骤3：手工上色（核心工序）
  参照飞虹塔实际色彩照片 → 丙烯逐层上色 → 做旧效果(选做)
  重点：琉璃的"通透感"靠多层薄涂+珠光粉叠加实现
  
步骤4：封层保护
  哑光/亮光清漆喷涂 → 干燥4小时

步骤5：安装磁铁+包装
  背面打孔嵌入磁铁 → 卡纸+透明袋 → 套装装铁盒
```

| **包装** | 棉麻袋 + 说明卡 |

#### 为什么用 UV 树脂仿琉璃？

```
真正琉璃烧制（800°C+，需要窑炉和专业设备）→ 不适合居家
UV树脂仿琉璃的优势：
  ✅ 通透度好，可叠加金色/珠光粉模拟琉璃质感
  ✅ UV灯照射3分钟固化，无需等待
  ✅ 硅胶模具+树脂，居家即可操作
  ✅ 材料成本低（¥3–5/件树脂）
  ✅ 失败可回收——未固化的树脂可擦掉重来
```

#### 系列规划

| 系列 | 造型 | 配色 | 售价 |
|------|------|------|:---:|
| **塔影** | 飞虹塔十三层轮廓 | 7色各一款 | ¥78 |
| **飞天** | 壁画飞天剪影 | 赭红/石青/金 | ¥88 |
| **莲心** | 仰覆莲花 | 粉/白/金 | ¥68 |
| **瑞兽** | 塔身脊兽 | 琉璃黄/翡翠绿 | ¥88 |

#### UV 树脂仿琉璃工艺（居家SOP）

```
材料准备：
  - UV树脂(高透型)        ¥30–50/200g
  - 珠光粉(7色套装)       ¥20–30
  - 金箔碎片              ¥10–20
  - 硅胶模具(3D打印原型翻制) ¥15–30/个
  - UV灯(36W以上)          ¥50–80
  - 色精(透明型)           ¥10–20

操作步骤：
  1. 树脂+珠光粉调色 → 搅拌至无颗粒(2min)
  2. 灌入模具 1/3 → UV灯照射30秒(底层固化)
  3. 放入金箔碎片 → 灌注剩余树脂 → UV灯照射3分钟(完全固化)
  4. 脱模 → 检查有无气泡/残缺
  5. 打磨边缘 → 抛光(可选)
  6. 装配钥匙扣/手机链配件

单件工时：15–20min / 件材料成本：¥3–8
```

### 💡 产品五：飞虹塔纸雕夜灯

#### 产品详情

| 项目 | 说明 |
|------|------|
| **尺寸** | 约 15cm×15cm×5cm（灯箱）+ 底座 |
| **材质** | 多层特种纸激光雕刻 + 榉木底座 + 暖白LED灯带 |
| **供电** | USB 充电 / 电池 |
| **层数** | 5–7 层纸雕，从近景到远景 |

#### 纸雕层次设计

```
第1层(最前)：飞虹塔轮廓剪影——黑色/深灰纸
第2层：塔身琉璃砖雕细节——深蓝纸
第3层：寺庙古柏/松树——深绿纸
第4层：远山(霍山)——浅灰纸
第5层(背景)：天空/云/月——白/米白纸
     ↓
  LED暖光从背后打来 → 层层叠透 → 立体光影效果
```

> **生产方案**：设计文件 → 淘宝激光雕刻代工(按张计费 ¥3–8/张) → 回来自己组装+底座+包装

#### 工艺路线

```

  适合唯一原型制作，不适合量产 → 做一件展示用

路线二：3D打印 + 翻模
  ① 找3D建模师根据实测数据建飞虹塔3D模型(¥1000–3000)
  ② 3D打印高精度原型(SLA打印，¥200–500/件)
  ③ 硅胶翻模(¥30–50/模具)
  ④ 树脂灌注+固化+脱模
  ⑤ 手工上色(最耗时，约2–4小时/件)
  ⑥ 装底座+编号证书
  → 适合小批量(50–200件)，单件成本 ¥80–150

路线三：对接专业模型厂
  东莞/义乌有大量做建筑模型的工厂
  起订量 500–1000，单件成本 ¥50–100
  → 适合大批量
```
