## 一、为什么做香道禅修线？

### 广胜寺的独特优势

```
其他文创品类（纸品/布艺/琉璃）→ 视觉为主
香道禅修类 → 视觉 + 嗅觉 + 触觉 + 故事 = 四维体验

寺庙文创做"香"天然合理：
  ├─ 寺庙本就与香火不可分割
  ├─ "禅修""疗愈"是当前高净值女性的内容热点
  ├─ 香薰品类在电商增速 30%+ YoY
  ├─ 与现有浮雕蜡烛产品线打通（共享蜡/精油供应链）
  └─ 客单价高、复购率高（用完会回购）
```

### 与现有蜡烛产品线的协同

| 维度 | 现有蜡烛线 | 禅修香道线 |
|------|----------|-----------|
| 共享材料 | 大豆蜡、椰子蜡、精油 | ← 完全复用 |
| 共享工艺 | 融蜡/入模/雕刻 | ← 蜡烛部分复用 |
| 新增工艺 | — | 合香配比、线香制作、香丸搓制 |
| 共享客群 | 精致女性和香薰爱好者 | ← 高度重叠 |
| 差异化 | 视觉艺术 | 禅修体验 + 文化IP |

### 🪵 产品二：合香线香套装

#### 产品详情

| 项目 | 说明 |
|------|------|
| **规格** | 管装 30 支 or 盒装 50 支 |
| **长度** | 约 15cm（标准线香长度） |
| **燃烧时间** | 约 30–40 分钟/支 |
| **材质** | 天然香粉（檀香/沉香/柏木等）+ 印尼楠木粘粉 |
| **包装** | 牛皮纸管/竹筒 + 棉麻布袋 |

#### 合香基础配方（居家可操作）

```
基础配比（重量比）：
  主香料 60%  → 决定主体香气（檀香粉/沉香粉/柏木粉）
  辅香料 25%  → 丰富层次（乳香粉/藿香粉/丁香粉/肉桂粉）
  粘粉 15%   → 成型必需（印尼楠木粘粉，天然无味）

广胜寺三个香方：

香方一：飞虹清供
  檀香粉 50% + 柏木粉 10% + 乳香粉 15% + 藿香粉 10% + 楠木粘粉 15%
  → 肃穆、庄严的寺庙正殿香气

香方二：金藏书香  
  沉香粉 30% + 白檀粉 20% + 丁香粉 10% + 龙脑 5% + 藿香粉 20% + 粘粉 15%
  → 清雅的书卷气，适合书房/阅读时点燃

香方三：山居岁月
  柏木粉 40% + 艾草粉 10% + 薄荷粉 5% + 肉桂粉 10% + 甘松粉 20% + 粘粉 15%
  → 自然的山林气，适合日常居家
```

#### 线香制作流程（居家SOP）

```
材料准备：
  香料粉(按配方混合)、楠木粘粉、纯净水
  工具：研钵/料理机、筛网(100目)、挤香器(手动/电动)、晾香板

步骤：
  1. 香料研磨 → 料理机打到最细 → 过100目筛
  2. 混合 → 香料粉+粘粉+少量水 → 和成面团状
  3. 醒泥 → 保鲜膜包裹静置 30min（使水分均匀）
  4. 挤香 → 放入挤香器 → 挤出直径 2–3mm 的线香条
  5. 理直 → 在晾香板上排列整齐，轻压理直
  6. 晾干 → 阴凉通风处晾 2–5 天（不能晒！会开裂或变味）
  7. 切齐 → 干透后裁成 15cm 标准长度
  8. 包装 → 入管/入盒

单批制作时间：约 1h 和泥+挤香 + 2–5天晾干
材料成本：¥15–30/管(30支)
```

### 🟤 产品三：禅香丸礼盒

> 香丸是中式合香的高级形态——比线香更有"手作温度"

#### 产品详情

| 项目 | 说明 |
|------|------|
| **规格** | 12 颗/盒（6种各2颗 or 单一方12颗） |
| **直径** | 约 1.5–2cm |
| **材质** | 香粉 + 炼蜜（蜂蜜熬煮浓缩） |
| **使用方式** | 放入电子熏香炉/蜡烛香薰炉加热 → 散发香气 |
| **包装** | 陶瓷小罐分装 + 木盒外盒 |

#### 制作流程

```
1. 炼蜜：蜂蜜小火熬煮去水分，熬至"滴水成珠"（滴入冷水不散）
2. 合香：香料粉+炼蜜揉和成团（蜜量刚好能成团不粘手）
3. 醒香：保鲜膜包好静置 1–2 天（香气融合）
4. 搓丸：取小块搓圆 → 标准重量 3–5g/颗
5. 挂衣(可选)：在香丸外裹一层极细香粉(如檀香粉)
6. 晾干：阴凉通风处晾 1–3 天
7. 包装：每颗入独立小陶罐，套装入木盒
```
