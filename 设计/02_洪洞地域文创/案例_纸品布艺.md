# 🎨 案例二：广胜寺纸品布艺系列

> **核心 IP**：元代壁画飞天 + 赵城金藏 + 铁佛
> **一句话**："把寺观壁画穿在身上，把千年经文握在手里"

---

## 一、IP 深度解读

### 元代壁画（中国寺观壁画巅峰之一）

```
广胜寺水神庙壁画是中国现存最完整的元代戏曲壁画
  ├─ 面积：约 200 平方米
  ├─ 内容：元代杂剧演出图、祈雨图、龙王行雨图、宫廷生活图
  ├─ 价值：中国戏曲史上的"第一手影像资料"
  ├─ 人物：飞天、乐伎、舞伎、官员、百姓——数百个人物
  └─ 色彩：赭红底 + 石青、石绿、金粉、墨线勾勒
```

| 可提取设计元素 | 适合产品 |
|--------------|---------|
| 飞天/乐伎线描 | 丝巾、书签、明信片、贴纸 |
| 壁画配色系统（赭红/石青/石绿/金） | 全系列色彩体系 |
| 祈雨/行雨图叙事 | 丝巾构图（故事性构图） |
| 杂剧人物 | 明信片、手账贴纸（趣味向） |
| 藻井/边饰纹样 | 和纸胶带连续纹样 |

---

### 赵城金藏（国家宝藏）

```
├─ 刻印年代：金皇统九年（1149年）开雕，历时约30年
├─ 体量：约 7000 卷，现存 4800 余卷
├─ 地位：与敦煌遗书、永乐大典、四库全书并称为中国"四大宝藏"
├─ 字体：典型金代刻经体——楷书方正端庄
└─ 故事：抗日时期八路军从日军包围中抢救金藏的传奇
```

| 可提取设计元素 | 适合产品 |
|--------------|---------|
| 经文楷书片段 | 书签、笔记本、帆布袋 |
| 经折装帧形式 | 笔记本/手账的外形设计 |
| "金藏"二字 | 品牌logo/印章 |
| 经文木版印刷效果 | 明信片、装饰画背景 |

### 📖 产品二：金藏经折装笔记本

| 项目 | 说明 |
|------|------|
| **装帧** | 经折装（风琴折） |
| **封面** | 硬壳裱布/裱纸 + 烫金"金藏"字样 |
| **内页** | 120g 轻型纸，素白，每页边缘压印经文暗纹 |
| **尺寸** | A6（10.5cm×14.8cm） |
| **页数** | 约 80 页（展开长约 8 米） |

#### 设计亮点

```
封面设计：
  ┌────────────────────┐
  │  暗红/藏蓝裱布       │
  │  烫金：赵城金藏四字   │
  │  （取金藏原本刻经体）  │
  │  下方：飞虹塔小剪影   │
  └────────────────────┘

内页暗纹：
  每页右下角/中间 → 浅灰印金藏经文片段水印纹
  不干扰书写，但翻看时"经文在纸中若隐若现"

扉页：
  印一段金藏抢救故事（八路军从日军包围中运出金藏）
  → 增加文化厚度和话题性
```

> **生产**：温州/广州文具代工厂，起订量 300–500 本，单本成本 ¥15–25，售价 ¥58–88。

### 🧣 产品五：飞天壁画数码印花丝巾

> 与现有「产品二：植物染丝巾」互补，走数码印花路线

| 项目 | 说明 |
|------|------|
| **尺寸** | 53cm/68cm/90cm 三种 |
| **材质** | 100%桑蚕丝素绉缎 |
| **工艺** | 高清数码印花 + 手工卷边 |
| **定价** | 53cm ¥228 / 68cm ¥358 / 90cm ¥498 |

#### 三个系列设计

| 系列 | 构图 | 色彩 | 故事 |
|------|------|------|------|
| **乐舞飞天** | 中心一飞天主图 + 四角散花纹 | 赭红底+石青石绿+金 | 元代壁画的音乐与舞蹈 |
| **琉璃色谱** | 几何色块拼接 + 塔形剪影 | 7色渐变 | 飞虹塔的七彩琉璃 |
| **铁佛禅意** | 唐风佛像剪影 + 莲纹铺底 | 铁灰+金+暗红 | 铁佛的沉静力量 |

#### 数码印花 vs 植物染路线对比

| 维度 | 数码印花 | 植物染 |
|------|---------|--------|
| 图案复杂度 | ✅ 可印任何精细图案 | ❌ 扎染/蜡染局限大 |
| 色彩精准度 | ✅ 所见即所得 | ❌ 每批有差异 |
| 独一无二性 | ❌ 每件一样 | ✅ 孤品 |
| 生产效率 | ✅ 工厂印好+回来卷边 | ❌ 全程手工 1–3天 |
| 售价天花板 | ¥228–498 | ¥228–980 |
| 适合场景 | 景区走量、多图案系列 | 线上高定、收藏级 |

> **策略**：数码印花做"量款"（景区+线上走量），植物染做"孤品款"（线上限量）。

### 🎐 产品七：古法香囊

| 项目 | 说明 |
|------|------|
| **尺寸** | 约 8cm×6cm |
| **材质** | 真丝/棉麻 + 中药香粉 |
| **工艺** | 手工缝制 + 抽绳 |
| **定价** | ¥48–98 |

#### 香方 × 广胜寺元素

| 香方名 | 香料 | 寓意 | 布料色 |
|--------|------|------|:---:|
| **飞虹清韵** | 檀香+柏木+薄荷 | 塔下古柏清风 | 琉璃蓝 |
| **金藏书香** | 藿香+丁香+白芷 | 经阁书卷气 | 米黄 |
| **霍泉芳草** | 艾草+薄荷+薰衣草 | 霍泉边的花草 | 浅绿 |
| **铁佛禅定** | 沉香+甘松+乳香 | 铁佛静坐入定 | 铁灰 |

#### 制作流程

```
1. 裁剪布料（真丝/棉麻方布 14cm×14cm）
2. 缝三面 + 留口（缝纫机 or 手工）
3. 翻面 → 填入香粉+棉花混合物
4. 收口缝绳 → 穿绳 → 打流苏结
5. 单件工时：15–25min / 材料成本：¥8–15
```
