## 4. 设计原则

- 洪洞文创只做“年轻化、可买、可送、可复购”的产品
- 先样品、后小批、再放量
- 先卖套装，再卖单品
- 所有新增内容都要回到“谁做、做什么、多少钱、多久做完”
