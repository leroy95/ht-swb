> **原则**：目录优先，产品其次，版本最后

---

## 2. 洪洞线的三级结构

- **第 1 级：目录**
  - `产品目录总览.md` 负责总览全部产品和版本入口
- **第 2 级：产品**
  - 每个产品一个目录，例如 `飞虹塔冰箱贴/`
- **第 3 级：版本**
  - `基础版.md` 写共性信息
  - `春节版.md`、`礼盒版.md`、`国庆版.md`、`联名版.md` 只写差异

## 4. 使用原则

1. 先看总览，再看产品，再看版本
2. `基础版.md` 只写产品共性信息，不写节日差异
3. 版本文件只写差异，不重复基础版
4. 新增产品先补目录，再补基础版，最后补版本
5. 所有内容保持 V1.0.0
