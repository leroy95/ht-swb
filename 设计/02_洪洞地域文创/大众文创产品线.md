## 四、渠道执行细节

### 景区谈判（关键一步）

```
准备工作（谈判前必须带齐）：
  □ 全部样品（15款实物，不是照片）
  □ 报价单（景区进货价 = 售价 × 65-70%）
  □ 展架方案（小体积桌面展架，不占空间）
  □ 补货方案（每周补一次，微信报缺货）

谈判对象优先级：
  ① 景区主入口商店（流量最大）
  ② 景区出口商店（游客快走了才逛）
  ③ 景区内个体商户（决策快，但铺面可能小）

分成底价：
  25% → 最佳（争取）
  30% → 可以接受
  35% → 只放¥68以上的高利润产品
  40%+ → 不做
```

### 广胜寺日销估算

```
广胜寺日均游客：约 1,500-2,500人（旺季）/ 500-800人（淡季）
进入商店的比例：约 30-50%
浏览文创的比例：约 20-30%
实际购买的比例：约 5-10%

按保守算：
  日均1500人 × 30%进店 × 20%看文创 × 5%购买
  = 日均4.5单
  
  客单价按¥40（买一个冰箱贴+一张明信片）
  = 日均¥180 → 月销¥5,400

旺季翻倍：月销¥10,000-12,000
淡季减半：月销¥2,500-3,000
```

### 景区集章打卡（第3月启动）

```
操作：
  ① 在广胜寺设3个盖章点（入口/飞虹塔前/出口商店）
  ② 卖集章护照本 ¥12（含3个章位）
  ③ 集满3个章 → 出口商店换冰箱贴一个（成本¥6）
  ④ 游客自发在小红书发"广胜寺集章攻略"

为什么管用：
  → 护照本¥12 = 纯利润¥10
  → 送¥6冰箱贴 → 游客觉得"赚了" → 实际我们赚¥4
  → 游客发小红书 → 免费引流
  → 集章的人必逛商店 → 提高进店率
```
