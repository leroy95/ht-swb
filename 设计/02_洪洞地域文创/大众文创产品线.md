# 🛍️ 洪洞文创产品线（V1.0.0）

> **定位**：洪洞文创线 = 创新大众线
> **一句话**：把洪洞的文化符号，做成年轻人愿意买、愿意拍、愿意送、愿意复购的日常伴手礼
> **版本约束**：本文件仅服务 V1.0.0，不做版本升级，不堆叠无效内容

---

## 1. 核心定位

### 1.1 做什么
- 做洪洞本地 IP 的**景区伴手礼、轻礼品、节日礼盒、家用纪念品**
- 先做游客会顺手买的，再做老客会复购的
- 以“文化识别度 + 轻量化 + 便于携带 + 价格亲民”为基本原则

### 1.2 不做什么
- 不做高研发、高库存、重资产定制
- 不做只看起来漂亮但不能量产的空想产品
- 不把手工文创线的高端工艺直接搬来做大众线

### 1.3 价格带
- 引流款：¥5–22
- 主销款：¥22–68
- 形象款：¥68–198
- 首发主力放在 **¥22–68** 区间

## 4. 首发 5 款详细版

- **工艺**：压铸、抛光、上色、背磁
- **核心卖点**：一眼识别飞虹塔，适合游客即买即带走
- **文化内涵**：借“琉璃塔”的地域名片，把洪洞最强 IP 做成高识别度小物件
- **使用场景**：景区柜台、伴手礼、旅行纪念、冰箱/办公桌装饰

## 6. 包装标准

### 6.1 包装结构
- **引流款**：卡纸 + 透明袋，轻、便宜、好陈列
- **主销款**：纸袋 / 纸盒 + 产品卡
- **形象款**：礼盒 / 抽屉盒 + 内托 + 赠卡

### 6.2 规格建议
- 冰箱贴/书签：卡纸背卡 + OPP 袋，袋厚 0.05mm 以上
- 明信片：套袋 + 纸封套，避免边角折损
- 手账本：牛皮纸封套或书脊护套
- 帆布袋：独立折叠后入袋，防脏防皱

### 6.3 视觉标准
- 统一用：琉璃蓝、朱红、金色、米白
- 主视觉只保留 1 个核心 IP 元素，不堆图
- 包装上必须有：品牌名、产品名、产地、日期信息
- 礼盒正面要一眼看出“送礼感”
- 字体建议：黑体/宋体混用，标题用厚重黑体，说明信息用清晰宋体

### 6.4 包装落点
- 景区柜台：易拿、易看、易结账
- 私域发货：抗压、抗摔、配说明卡
- 节日款：礼盒优先，单品做补充

## 7. 说明书标准

### 7.1 必备字段
1. 产品名称
2. 对应洪洞 IP
3. 材质说明
4. 使用方式
5. 保养方法
6. 安全提示
7. 制作/出品信息
8. 匠人/品牌信息（可选）

### 7.2 标准文案结构
- **文化故事**：对应哪一处洪洞 IP
- **使用方式**：怎么佩戴、摆放、保存
- **保养说明**：防潮、防晒、防压等
- **安全提示**：小零件、易碎、远离火源等
- **匠人信息**：如为手作参与，可加制作者/工坊名片

### 7.3 纸张与工艺
- 纸张：300g–350g 铜版纸或特种纸
- 尺寸：A6/A5 以内，优先单页或对折页
- 印刷：四色印刷为主，礼盒款可加烫金/局部 UV
- 原则：一页讲清，不写长篇大论，图示要直观

### 7.4 说明书原则
- 礼盒款说明书可以附一张“送礼话术卡”
- 大众款说明书尽量短，避免增加成本和阅读负担

## 8. 复购设计

- **套装升级**：单品 → 三件套 → 礼盒
- **节日限定**：春节、国庆、母亲节、旅游旺季限定包装
- **老客回购**：收集款式、补齐系列、节日换包装
- **二次购买触发**：明信片、贴纸、轻礼袋最适合复购
- **耗材补充**：明信片补卡、礼袋补装、包装补件

## 9. 渠道策略

| 渠道 | 角色 | 说明 | 建议分成/利润 |
|---|---|---|---|
| 景区店 | 主销渠道 | 走量、做曝光、做文化记忆 | 分成 25%–30% |
| 书店/文创店 | 提质渠道 | 提升文化感与连带购买 | 分成 20%–28% |
| 电商 | 补充渠道 | 承接礼盒、异地购买、复购 | 自营为主，毛利优先 |
| 私域 | 复购渠道 | 节日礼物、限定款、老客回购 | 用组合价提升客单 |
| 直播/短视频 | 种草渠道 | 负责内容曝光与新品测试 | 以样品引流、成交转私域 |

### 9.1 渠道组合建议
- 首发优先：景区店 + 私域 + 短视频
- 稳定后补：书店/文创店 + 电商
- 节日冲刺：礼盒在线上集中售卖，景区店负责散单

### 9.2 利润分配建议
- 景区店分成：25%–30%
- 书店/文创店分成：20%–28%
- 自营电商：主推中高客单和礼盒
- 私域：主推套装、限定和补货

## 10. 安全分级

| 风险类型 | 适用 SKU | 等级 | 提示 | 检测/控制 |
|---|---|---|---|---|
| 小零件 | 冰箱贴、书签、印章 | 中 | 3 岁以下避免接触/吞咽风险 | 拉力/磁力测试、边角检查 |
| 金属边角 | 书签、金属挂件 | 中 | 需去毛刺、圆角处理 | 触摸检查、毛刺复检 |
| 易碎 | 纸雕夜灯、礼盒摆件 | 中 | 外包装加缓冲 | 跌落/挤压测试 |
| 材质过敏 | 合金、香料、胶水 | 中 | 说明书写明过敏提示 | 材料合格证明、气味测试 |
| 易燃 | 纸品、蜡类、香类 | 中 | 远离火源、避免高温暴晒 | 阻燃/耐热提醒标识 |

### 10.1 安全原则
- 风险提示必须写进说明书和外包装
- 面向亲子场景的产品，必须降低小零件和易燃风险
- 需要接触皮肤的产品，先做材料说明与过敏提醒
