# 🗺️ 地域文创通用框架

> **可复用方法论**：任何景区/地域都能套用的文创产品开发框架
> 创建日期：2026-06-18

---

## 一、核心公式

```
地域文创产品 = 地域IP元素 × 产品载体类型 × 手工/半手工工艺

成功关键：三个维度的交叉点找对，而不是盲目堆砌
```

---

## 二、地域 IP 提取四步法

### Step 1：IP 元素扫描（四象限法）

```
            视觉冲击力强
                 │
        ┌────────┼────────┐
        │  ②    │   ①   │
        │ 隐藏   │ 明星   │
 知名度低│ 宝石   │ IP    │知名度高
        │  ④    │   ③   │
        │ 潜力   │ 陪衬   │
        │ 挖掘   │ 元素   │
        └────────┼────────┘
                 │
            视觉冲击力弱
```

```
① 明星 IP（知名度高 + 视觉强）→ 做核心产品、重投入
② 隐藏宝石（知名度低 + 视觉强）→ 做差异化、讲好故事
③ 陪衬元素（知名度高 + 视觉弱）→ 做辅助元素、不独立成系列
④ 潜力挖掘（知名度低 + 视觉弱）→ 暂不做 or 作为系列彩蛋
```

### Step 2：四要素对照表

| 维度 | 要提取什么 | 怎么用 | 广胜寺案例 |
|------|----------|--------|----------|
| ① **地标建筑** | 整体轮廓、局部结构、材质特征、色彩 | 造型、剪影、线条、结构提取 | 飞虹塔→冰箱贴造型、十三层密檐→纸雕灯层次 |
| ② **历史文物/壁画** | 人物、图案、纹样、色彩系统、材质 | 图案设计、配色方案、纹样提取 | 元代壁画→丝巾图案、壁画色谱→全系列色彩体系 |
| ③ **非遗技艺** | 工艺本身、工具、流程、成品特征 | 做DIY套装、融入制作工艺 | 琉璃烧制→仿琉璃树脂工艺 |
| ④ **自然风物** | 植物、山水、气候、特产 | 色彩、材质、气味、香型 | 霍泉→薄荷绿茶香型、古柏→柏木香 |

### Step 3：IP 转产品要素

```
IP元素 → 设计要素 → 产品载体

例子：
  飞虹塔琉璃砖的蓝色 → 提取为"孔雀蓝"色号 → 应用到丝巾配色、蜡烛调色
  元代壁画飞天的手势 → 提取为线描剪影 → 应用到书签、挂件、贴纸
  金藏经文楷书 → 提取为字体资产 → 应用到所有文字类产品
```

### Step 4：可产品化评估

| 评估维度 | 权重 | 评分标准 |
|---------|:---:|---------|
| 视觉冲击力 | 25% | 拍照/视频出片率 |
| 故事性 | 20% | 有没有可讲的故事 |
| 辨识度 | 20% | 消费者一眼能认出 |
| 转化难度 | 20% | 容不容易做成产品 |
| 传播性 | 15% | 适不适合社交媒体传播 |

## 三、产品载体选择矩阵

### 按开发难度×市场匹配度

```
高市场匹配
  ↑
  │  纸品类(明信片/书签/贴纸)     丝巾/布艺类        琉璃/陶瓷类
  │       ↓ 基础线                      ↓ 利润线          ↓ 核心形象线
  │
  │  文具/胶带/冰箱贴              香薰/蜡烛类        刺绣/微钩类
  │       ↓ 引流线                      ↓ 复购线          ↓ 高定线
  │
  │  数字卡片/印章                  DIY套装类          模型/摆件类
  │       ↓ 补充线                      ↓ 体验线          ↓ 收藏线
  │
  └──────────────────────────────────────────────────────→ 开发难度
                    低 ←────────────────────→ 高
```

## 四、地域文创开发流程

### 标准 5 阶段流程

```
阶段一：IP调研（1–2周）
  □ 收集该地域所有可用的IP元素
  □ 四象限法分类排序
  □ 实地拍摄/扫描/采集素材
  □ 提炼色彩系统、纹样系统、造型系统
  □ 输出：IP元素库 + 设计素材包

阶段二：产品构思（1–2周）
  □ IP元素 × 产品载体交叉匹配
  □ 画出 5–8 个产品概念草图
  □ 评估开发难度和成本
  □ 选出 2–3 个首批试点产品
  □ 输出：产品概念方案

阶段三：样品打样（2–4周）
  □ 设计稿定稿（AI/PS设计文件）
  □ 找供应商打样（印刷/模具/配件）
  □ 自己动手做手工样品
  □ 拍摄产品图
  □ 输出：实物样品 + 产品图

阶段四：小批量测试（2–4周）
  □ 生产 50–200 件
  □ 线上测试（小红书发帖、私域群发售）
  □ 线下测试（景区商店/市集）
  □ 收集反馈 → 迭代
  □ 输出：测试数据 + 迭代方案

阶段五：正式上线（持续）
  □ 根据反馈迭代产品
  □ 扩量生产
  □ 铺渠道
  □ 内容营销持续产出
  □ 推出同系列第二、三款产品
```

## 五、各类型产品速配指南

### 什么IP适合什么产品？

| IP 特征 | 最适合的产品类型 | 为什么 |
|---------|---------------|--------|
| 建筑轮廓清晰、剪影好看 | 冰箱贴、书签、纸雕灯、丝巾 | 线条转化成产品的效果好 |
| 壁画/绘画丰富 | 丝巾、明信片、贴纸、DIY临摹 | 直接提取图案 |
| 有独特的色彩体系 | 全系列色彩统一 | 色谱 = 品牌色板 |
| 有宗教/精神属性 | 香道、蜡烛、禅修套装 | 精神体验 → 五感产品 |
| 有文字/典籍 | 书签、笔记本、帆布袋 | 经文/文字直接产品化 |
| 有非遗工艺 | DIY套装、成品展示 | 工艺 = 内容素材 |
| 自然景观优美 | 丝巾(山水)、蜡烛(气味)、树脂(干花) | 抽象化、意境化 |

## 七、各渠道适配策略

### 不同地域的产品渠道组合

| 地域类型 | 主渠道 | 次渠道 | 产品侧重 |
|---------|--------|--------|---------|
| **知名景区**（故宫/敦煌/兵马俑） | 景区商店 + 线上 | 批发给各地文创店 | 走量款为主(¥28–198)，爆款冰箱贴+明信片+贴纸 |
| **中型景区**（广胜寺/平遥/云冈） | 景区商店 + 线上种草 | 私域 + 市集 | 走量+利润(¥38–398)，丝巾+蜡烛+纸品 |
| **小众文保**（铁佛寺/小西天） | 线上内容种草 | 定制/限量 | 高客单价限量(¥198–980)，收藏级产品 |
| **非遗产地**（景德镇/宜兴） | DIY体验 + 线上 | 景区 + 市集 | DIY套装为主，体验驱动销售 |

## 八、执行清单

### 每进入一个新地域，需要完成的 10 件事

```
□ 1. 实地走访，拍摄 200+ 张素材照片
□ 2. 提取 3–5 个核心 IP 元素（四象限法排序）
□ 3. 提炼 1 套色彩系统（5–8 色）
□ 4. 整理 1 套纹样/图形素材库
□ 5. 写出每个 IP 的"一句话故事"（产品卡片用）
□ 6. 画出 5–8 个产品概念草图
□ 7. 选 2–3 个首批产品打样（1 走量 + 1 利润 + 1 形象）
□ 8. 拍 1 组高质量产品图 + 1 条制作过程视频
□ 9. 小红书发 3–5 条内容测试反应
□ 10. 收集反馈 → 迭代 → 决定是否扩产
```

## 九、避坑指南

### 常见错误 & 对策

| 错误 | 后果 | 对策 |
|------|------|------|
| ❌ 想把所有 IP 元素都做一遍 | 产品线散乱、没有记忆点 | ✅ 聚焦 1–2 个明星 IP 做透 |
| ❌ 设计照搬原物不加工 | 太"文博"像教材、不"文创" | ✅ 提取+简化+再设计，现代审美翻译 |
| ❌ 只做高客单价 | 景区走不动量 | ✅ 必须有 ¥28–68 的随手买产品 |
| ❌ 忽略景区渠道分成 | 利润被渠道吃掉 | ✅ 定价时预留 20–30% 渠道费 |
| ❌ 不做版权/授权功课 | 侵权风险 | ✅ 事先确认文物的版权/使用权归属 |
| ❌ 一次性做太多 SKU | 库存压力、资金积压 | ✅ 3 款起步，验证后扩充 |
