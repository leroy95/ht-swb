## 2. 采购清单

### 2.1 必采项
- 金属坯件 / 合金模具
- 珐琅或填色材料
- 纸张 / 特种纸 / 烫金耗材
- 帆布 / 印花耗材
- 丝巾面料与印花工序
- 礼盒包材与内托
- 背卡、说明卡、吊牌

### 2.2 采购原则
1. 设计稿先定，再下单打样
2. 先做最小起订量，不追求一口气压货
3. 包装尽量独立采购，避免工厂加价
4. 春节 / 国庆 类节日款提前 3–6 周锁定产能

### 2.3 供应链方向

| 产品 | 采购方向 | 备注 |
|---|---|---|
| 金属冰箱贴/书签 | 东莞 / 中山金属厂 | 珐琅、蚀刻、压铸成熟 |
| 明信片/手账本 | 温州印刷 / 文具厂 | 适合小批量、交期短 |
| 帆布袋/贴纸/印章 | 义乌 / 温州 | 起订友好，成本低 |
| 丝巾 | 杭州 / 苏州数码印花厂 | 更适合形象款 |
| 礼盒包装 | 温州 / 本地包材店 | 分批采购，先轻后重 |

## 3. 打样优先级

### 3.1 优先打样 5 款
1. 飞虹塔金属冰箱贴
2. 飞虹塔金属书签
3. 飞虹塔明信片套装
4. 金藏经文手账本
5. 壁画帆布袋

### 3.2 节日前置打样
- 春节款：节前 4–6 周完成图稿与样品确认
- 国庆款：节前 3–4 周完成图稿与样品确认
- 节日前不再新增高风险 SKU，只做确认与补货

### 3.3 打样原则
- 先确认外观，再确认成本
- 先确认样品，再确认大货
- 先确认卖点，再确认扩产

## 4. 成本与定价逻辑

### 4.1 走量款
- 成本占售价 20%–35%
- 适合景区、夜市、私域基础转化

### 4.2 利润款
- 成本占售价 20%–40%
- 适合礼盒、套装、收藏类产品

### 4.3 形象款
- 可接受更高成本，但必须具备礼品感与文化辨识度
