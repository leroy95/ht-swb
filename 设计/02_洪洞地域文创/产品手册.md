## 一、洪洞文化 IP 全景

### 五个层次

```
第一层 · 国家级IP（全国人民都知道）
  ├── 🥇 广胜寺飞虹塔 —— 中国最美琉璃塔，86版《西游记》取景地
  ├── 🥈 洪洞大槐树 —— "问我祖先在何处，山西洪洞大槐树"，全球华人的根
  └── 🥉 苏三监狱 —— "苏三离了洪洞县"，京剧《玉堂春》经典唱段

第二层 · 文物级IP（文博爱好者追捧）
  ├── 广胜寺元代壁画 —— 中国现存最完整的元代戏曲壁画
  ├── 赵城金藏 —— 国家宝藏，与敦煌遗书齐名
  └── 广胜寺铁佛 —— 唐代铁铸佛像，高6米

第三层 · 建筑美学IP（设计素材矿）
  ├── 飞虹塔琉璃砖雕（佛龛、菩萨、飞天、瑞兽、花卉）
  ├── 飞虹塔建筑结构（八角十三层密檐、斗拱、琉璃瓦当）
  └── 广胜寺古柏（千年古柏，霍泉边的自然禅意）

第四层 · 自然风物IP
  ├── 霍泉 —— 山西名泉，水质清冽
  ├── 霍山 —— 太岳山主峰，山水画卷
  └── 洪洞地方风物（红枣、蒸饭、莲藕、剪纸）

第五层 · 品牌延展IP（差异化机会）
  ├── 梁思成林徽因测绘故事 —— 1930s 建筑史经典案例
  ├── 八路军抢救金藏故事 —— 抗日红色文化
  └── 洪洞道情/地方戏曲 —— 非遗传承
```

## 四、洪洞特色原料本地化

### 在洪洞就能买到/采购的

```
□ 石膏粉 → 洪洞建材市场（¥3/kg，比网上便宜一半）
□ 丙烯颜料 → 洪洞文具店/画材店
□ 中药香粉 → 洪洞中药房（檀香/柏木/藿香/艾草/丁香/白芷）
□ 棉麻布 → 洪洞布行（做香囊用）
□ 棉花/丝绵 → 洪洞百货/床上用品店（香囊填充）
□ 宣纸 → 洪洞文具店（拓印套装用）
□ 蜂蜡 → 洪洞本地养蜂户（天然蜡烛原料，霍山脚下多养蜂）
□ 干花材 → 霍山/霍泉边野花自采+干燥（零成本！）
□ 包装纸袋 → 洪洞印刷店
□ 牛皮纸盒 → 洪洞包装材料店

## 七、第一批打样清单

### 最优先打样的 5 款（按重要程度排序）

```
□ 1. 飞虹塔琉璃冰箱贴（石膏翻模+手绘）
     → 原因：IP最强关联、入门级工艺、适合培训女工
     → 需要：飞虹塔局部元素的3D原型 → 翻硅胶模具 → 试做5个颜色

□ 2. 飞天壁画丝巾（53cm小方巾）
     → 原因：客单价高、线上爆款潜力、外包印花容易出样品
     → 需要：设计飞天图案矢量稿 → 找杭州丝绸厂打样2条

□ 3. 禅香浮雕蜡烛（飞虹塔影款）
     → 原因：与现有蜡烛产品线打通、高毛利、内容素材多
     → 需要：调香方 → 做蜡坯 → 试雕刻塔形

□ 4. 手撕棉纸书签（金藏经文款）
     → 原因：最快出成品、成本最低、适合当赠品/引流
     → 需要：设计经文排版 → 找印刷店打样10张

□ 5. 古法香囊（霍泉芳草款）
     → 原因：入门级手工、本地中药房就能买到材料
     → 需要：选布料+配香方 → 试做5个
