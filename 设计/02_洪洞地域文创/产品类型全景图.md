## 二、各类详解

### 类型 1：琉璃/玻璃类 🥇

> **广胜寺第一优先品类——飞虹塔是中国琉璃塔之王**

| 产品细分 | 材料/工艺 | 参考售价 | 单件工时 | 核心卖点 |
|---------|----------|:-------:|:------:|---------|
| 彩色琉璃冰箱贴 | 石膏翻模+手工上色仿琉璃质感 | ¥38–68 | 15min | 建筑局部：斗拱/脊兽/琉璃瓦/窗棂 |
| 琉璃挂件/钥匙扣 | 树脂+金粉调色仿琉璃 | ¥48–88 | 20min | 塔形/莲座/飞天剪影 |
| 琉璃色系书签 | 铜镀金+彩色珐琅 | ¥58–128 | 30min | 飞虹塔线条 + 琉璃七彩配色 |
| 琉璃摆件/镇纸 | 玻璃铸造 or 大漆+螺钿 | ¥198–588 | 2–4h | 微缩塔身/飞天像 |
| 琉璃灯/夜灯 | 亚克力激光雕刻+LED底座 | ¥128–258 | 1h | 塔形多层雕刻+暖光 |

**"仿琉璃"工艺路线（居家友好）**：

```
真正高温琉璃烧制（800°C+）→ 不适合居家生产

替代方案：
  方案A：石膏翻模 + 丙烯/珐琅手工上色 → 立体感强，居家可做
  方案B：UV树脂 + 珠光粉调色 → 通透感好，适合小件
  方案C：透明亚克力 + 激光雕刻 + 填色 → 适合平面产品（书签/夜灯）

推荐：方案A 做主推（冰箱贴/挂件），方案B 做高端线，方案C 做走量线
```

**广胜寺琉璃 IP 开发点**：

```
飞虹塔结构分解（13层密檐）：
  第1层 → 须弥座纹样（仰莲、覆莲、力士）→ 适合做浮雕冰箱贴
  第2–12层 → 琉璃砖雕（佛龛、菩萨、飞天）→ 适合做挂件/书签
  第13层 → 塔刹（宝珠、相轮）→ 适合做项链坠

色彩体系（七彩琉璃）：
  主色：琉璃黄、孔雀蓝、翡翠绿、玛瑙红、水晶紫、琥珀橙、珍珠白
  → 7 色可做 7 款冰箱贴，集齐全套 = 飞虹塔完整色谱
```

### 类型 2：纸品印刷类 🥈

> **开发最快、成本最低、适合景区测试市场**

| 产品细分 | 工艺 | 参考售价 | 备注 |
|---------|------|:-------:|------|
| 烫金明信片套装 | 烫金/烫银+浮雕压凹 | ¥28–48/套(6–8张) | 飞虹塔各角度+壁画飞天 |
| 手撕书签（棉纸+流苏） | 凸版+手工撕边+流苏 | ¥12–28/张 | 赵城金藏经文片段 |
| 经折装笔记本 | 手工装订+烫金封面 | ¥38–88 | 金藏经折形式+禅意留白 |
| 手绘打卡地图 | 插画+折页设计 | ¥18–38 | 广胜寺全景+集章点位 |
| 和纸胶带 | 连续图案印刷 | ¥15–28/卷 | 藻井纹样/琉璃色块/飞天 |
| 手账贴纸包 | 模切贴纸 | ¥12–28/套 | 飞虹塔+壁画元素+建筑局部 |

**开发要点**：
- 设计文件→交印刷厂（淘宝/1688 印刷定制店即可）
- 起订量：明信片 100 套起，贴纸 200 套起，胶带 100 卷起
- 关键在**设计**：需要有懂建筑/壁画的结构感 + 现代排版审美
- 纸张选品：明信片用 350g 棉纸/特种纸，书签用 250g 手撕棉纸

**广胜寺壁画丝巾系列构思**：

```
系列一：飞天乐舞
  元素：元代壁画中的飞天、乐伎、舞伎
  色彩：壁画原色系——赭红底+石青石绿+金粉点缀
  构图：中心飞天 + 四角散花 → 90cm 大方巾

系列二：琉璃色谱
  元素：飞虹塔琉璃砖的几何纹样 + 七彩渐变
  色彩：直接从塔上提取 7 色
  构图：渐变色块拼接 → 68cm 中方巾

系列三：金藏经文
  元素：赵城金藏中的经文片段（楷书、行书）
  色彩：素色系——米黄底+棕黑经文
  构图：经文竖排满铺 → 53cm 小方巾
```

**广胜寺禅香系列构思**：

```
香方一：飞虹禅韵
  主调：老山檀 + 柏木 + 乳香
  意境：飞虹塔下古柏森森，千年香火不息
  产品形态：浮雕蜡烛（塔形雕刻 + 木片烛芯）

香方二：金藏墨香
  主调：龙脑 + 白檀 + 丁香 + 藿香
  意境：金代藏经阁的书卷气
  产品形态：合香丸 + 迷你石雕香炉

香方三：霍泉清音
  主调：薄荷 + 绿茶 + 柑橘 + 草本
  意境：霍泉水的清冽甘甜
  产品形态：线香（适合春夏晨间）
```
