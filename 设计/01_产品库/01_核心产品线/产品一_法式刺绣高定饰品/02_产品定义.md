# 产品定义

## 1. 产品说明
- 产品名称：法式刺绣高定饰品
- 产品形态：胸针 / 发夹 / 耳环 / 手袋挂饰 / Choker
- 所属系列：核心产品线高定饰品组

## 2. 功能/用途
- 日常佩戴与搭配
- 节日送礼与纪念礼物
- 定制化品牌礼赠

## 3. 规格参数
- 尺寸：小型饰品为主，便于佩戴
- 材料：真丝欧根纱、米珠、亮片、金线、金属配件
- 工艺：法式钩针珠绣、链条绣、粒粒绣、垫绣、金线盘绣
- 包装：建议采用轻奢礼盒或布袋
- 其他：支持生辰色、字母、图案定制

## 4. 设计要点
- 造型要点：小而精、轮廓清晰、适合近看
- 视觉要点：珠光、金属感、层次感
- 使用体验要点：佩戴牢固、不压头、不过分笨重

## 5. 成本构成
- 材料成本：约 ¥20–60/件
- 加工成本：按手工工时核算
- 包装成本：礼盒 / 防尘袋 / 说明卡
- 物流成本：按单件体积重量估算
- 其他成本：打样、耗材、损耗

## 6. 风险点
- 手工一致性不稳定
- 串珠/固定结构易受工艺影响
- 复杂图案会拉长制作周期

## 7. 结论
- 先从简单图案与小件型态切入，逐步扩展复杂款。
