# v1.0

## 1. 版本目标
- 完成法式刺绣高定饰品的基础定义，形成可用于打样与内容展示的首个版本。

## 2. 版本内容
- 首批产品形态：胸针、发夹、耳环、手袋挂饰、Choker
- 风格关键词：东方美学、高定感、珠光层次、轻奢送礼
- 设计方向：青绿山水、四君子、敦煌色系、生辰定制、日常轻奢

## 3. 规格参数
- 尺寸：小型饰品为主
- 材料：真丝欧根纱、米珠、亮片、DMC 绣线、金线/银线、金属托件
- 工艺：法式钩针珠绣 + 传统刺绣针法组合
- 包装：建议礼盒化，增强送礼场景

## 4. 成本与售价
- 材料成本：胸针 ¥30–60 / 耳环 ¥20–45 / 发夹 ¥25–50
- 加工成本：按工时核算，首版以打样验证为主
- 总成本：视款式与工时浮动
- 建议售价：¥198–798

## 5. 适用场景
- 礼物
- 自戴搭配
- 定制活动礼赠
- 品牌形象展示

## 6. 生产注意事项
- 先控制图案复杂度，避免工时过长
- 固定结构要重点测试牢固度
- 先做小批量样品验证色彩与光泽

## 7. 风险与限制
- 手工差异属于产品特征，但需控制在可接受范围
- 亮片与米珠搭配需要避免廉价感
- 复杂图案会提高返工率

- 后续改动：依据打样反馈逐步优化
