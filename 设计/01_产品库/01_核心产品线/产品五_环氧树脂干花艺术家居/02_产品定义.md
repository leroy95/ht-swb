# 产品定义

## 1. 产品说明
- 产品名称：环氧树脂干花艺术家居
- 产品形态：杯垫 / 托盘 / 装饰画 / 收纳盒 / 手机壳 / 镇纸摆件 / 纪念定制
- 所属系列：核心产品线树脂家居组

## 2. 功能/用途
- 家居摆设与装饰
- 纪念封存与礼赠
- 内容拍摄与情感定制

## 3. 规格参数
- 尺寸：10cm、20–30cm、A4/A3、15–20cm、定制
- 材料：环氧树脂 AB 胶、硅胶模具、干花、压花器、砂纸、抛光膏
- 工艺：配比、搅拌、分层灌注、脱模、打磨抛光
- 包装：建议盒装或防震包装
- 其他：支持婚礼花材、宠物纪念等定制

## 4. 设计要点
- 造型要点：留白、景深、层次
- 视觉要点：透明感、花材质感、艺术感
- 使用体验要点：表面平整、边缘细腻、耐用稳定

## 5. 成本构成
- 材料成本：杯垫 ¥5–8 / 托盘 ¥20–40 / 装饰画 ¥30–50
- 加工成本：按灌注与打磨工时核算
- 包装成本：盒装 / 防震 / 标签卡
- 物流成本：按易碎品保护要求估算
- 其他成本：打样、损耗、耗材

## 6. 风险点
- 树脂黄变与气泡控制
- 花材含水导致腐烂
- 抛光工序耗时

## 7. 结论
- 先用低门槛小件验证工艺，再推进高客单定制件。
