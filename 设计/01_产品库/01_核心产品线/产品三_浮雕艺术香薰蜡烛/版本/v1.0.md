# v1.0

## 1. 版本目标
- 完成浮雕艺术香薰蜡烛的基础定义，形成可用于打样与内容展示的首个版本。

## 2. 版本内容
- 首批产品形态：圆柱形、方形、异形
- 风格关键词：艺术感、治愈感、轻奢感、桌面雕塑
- 设计方向：经典花纹、敦煌壁画、山水写意、定制字母、季节限定

## 3. 规格参数
- 尺寸：小号、中号、大号
- 材料：大豆蜡 / 椰子蜡、天然精油、木片烛芯、色粉
- 工艺：融蜡、雕刻、调香、抛光
- 包装：建议礼盒化

## 4. 成本与售价
- 材料成本：小号 ¥8–12 / 中号 ¥12–18 / 大号 ¥18–25
- 加工成本：按工艺复杂度核算
- 总成本：视尺寸与雕刻工序浮动
- 建议售价：¥128–388

## 5. 适用场景
- 家居摆设
- 香氛礼物
- 节日限定
- 拍照内容

## 6. 生产注意事项
- 蜡温与雕刻时机要重点控制
- 香型与图案需要相互匹配
- 先做小批量验证稳定性

## 7. 风险与限制
- 燃烧后浮雕会逐渐消失
- 香味强度与扩香范围需要测试
- 图案复杂度不宜过高

- 创建原因：配合目录重构，建立第一版产品样板
- 后续改动：依据打样反馈逐步优化
