# 产品定义

## 1. 产品说明
- 产品名称：广胜寺琉璃文创系列
- 产品形态：冰箱贴 / 挂件 / 书签尺 / 丝巾 / 纸雕夜灯 / 微缩模型
- 所属系列：地域文创·琉璃线

## 2. 功能/用途
- 景区伴手礼
- 文化传播与收藏
- 线上内容转化

## 3. 规格参数
- 尺寸：4–6cm、3–5cm、12cm、68cm、15cm灯箱、1:200–1:300 模型
- 材料：石膏、UV 树脂、黄铜、真丝、特种纸、亚克力
- 工艺：翻模、上色、蚀刻、数码印花、激光雕刻、3D 建模
- 包装：卡纸、透明袋、礼盒、展示盒
- 其他：支持套装化销售

## 4. 设计要点
- 造型要点：塔身轮廓、琉璃砖雕、色谱系统
- 视觉要点：七彩、透亮、建筑结构强
- 使用体验要点：易携带、易陈列、易传播

## 5. 成本构成
- 材料成本：按载体类型不同浮动较大
- 加工成本：手工上色与翻模占比高
- 包装成本：卡纸 / 礼盒 / 展示盒
- 物流成本：按易碎与大件分级
- 其他成本：打样、翻模、建模、损耗

## 6. 风险点
- 视觉很强但工艺复杂度不同
- 琉璃感的表达需要避免廉价化
- 量产与手工表现的平衡

## 7. 结论
- 先从冰箱贴、书签、挂件三类切入，再逐步扩展到丝巾与摆件。
