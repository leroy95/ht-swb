# v1.0

## 1. 版本目标
- 建立广胜寺琉璃文创系列的基础样板，验证琉璃塔 IP 的载体表达。

## 2. 版本内容
- 首批产品：冰箱贴、挂件、书签尺、琉璃色谱丝巾、纸雕夜灯、微缩模型
- 风格关键词：七彩、建筑、琉璃感、高辨识度
- 设计方向：从飞虹塔结构、琉璃色谱、塔身细节中提取视觉元素

## 3. 规格参数
- 纸品：明信片 / 书签 / 胶带
- 饰品：冰箱贴 / 挂件 / 书签尺
- 布艺：数码印花丝巾
- 摆件：夜灯 / 微缩模型

## 4. 成本与售价
- 材料成本：按载体不同浮动
- 建议售价：¥38–980
- 组合销售可提升客单价

## 5. 适用场景
- 景区销售
- 礼品采购
- 线上内容传播
- 收藏与摆设

## 6. 生产注意事项
- 先做低门槛纸品，再做复杂摆件
- 琉璃色谱需要统一管理
- 模型类需控制成本与交期

## 7. 风险与限制
- 工艺链条长
- 复杂产品不宜前期大量压货
- 视觉过强时要避免风格杂乱

- 创建原因：配合目录重构，建立地域文创案例样板
- 后续改动：依据市场反馈逐步细化
