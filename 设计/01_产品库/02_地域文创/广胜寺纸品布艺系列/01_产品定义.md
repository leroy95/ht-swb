# 产品定义

## 1. 产品说明
- 产品名称：广胜寺纸品布艺系列
- 产品形态：明信片 / 经折装笔记本 / 书签 / 和纸胶带 / 贴纸 / 丝巾 / 帆布袋 / 香囊
- 所属系列：地域文创·纸品布艺线

## 2. 功能/用途
- 伴手礼
- 文具与日常使用
- 线上传播与内容导流

## 3. 规格参数
- 明信片：15×10cm，8 张/套
- 书签：15×4cm，手撕棉纸
- 丝巾：53/68/90cm 真丝数码印花
- 帆布袋：35×40cm
- 香囊：8×6cm
- 其他：支持经折装笔记本、贴纸、胶带

## 4. 设计要点
- 造型要点：建筑线描、壁画人物、经文片段、连续纹样
- 视觉要点：赭红、石青、石绿、金色、米白
- 使用体验要点：轻便、好带、易买、易送礼

## 5. 成本构成
- 纸品成本低，适合快速验证
- 布艺成本中等，适合提高客单
- 工艺成本主要在设计与排版

## 6. 风险点
- 图案太满会失去现代感
- 纸品易显廉价，需控制材质与工艺
- 布艺产品要平衡视觉与日常使用性

## 7. 结论
- 优先推进纸品引流款，再延伸布艺礼赠款。
