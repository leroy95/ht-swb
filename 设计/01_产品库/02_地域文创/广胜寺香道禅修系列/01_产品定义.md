# 产品定义

## 1. 产品说明
- 产品名称：广胜寺香道禅修系列
- 产品形态：禅香蜡烛 / 合香线香 / 香丸 / 香薰石膏牌 / 香插 / 禅修体验套装
- 所属系列：地域文创·香道禅修线

## 2. 功能/用途
- 家居香氛
- 禅修体验
- 礼赠与内容传播

## 3. 规格参数
- 线香：15cm / 30–40 分钟
- 香丸：12 颗/盒
- 蜡烛：塔形浮雕 + 木片烛芯
- 石膏牌：6–8cm
- 香插：塔形 / 莲座 / 圆盘
- 其他：可组合为礼盒套装

## 4. 设计要点
- 造型要点：寺庙、塔、莲座、禅意图形
- 视觉要点：沉静、留白、自然材质
- 使用体验要点：香气稳定、包装有仪式感

## 5. 成本构成
- 香材与蜡材成本相对可控
- 包装与礼盒决定最终价格感
- 套装化能提升体验与毛利

## 6. 风险点
- 香气偏好主观性强
- 线香制作需要控制晾干过程
- 香丸与礼盒的体验要统一

## 7. 结论
- 先做石膏牌和线香引流，再推进蜡烛与礼盒。
