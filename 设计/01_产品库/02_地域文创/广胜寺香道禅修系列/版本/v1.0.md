# v1.0

## 1. 版本目标
- 建立广胜寺香道禅修系列的基础样板，验证香品与禅修体验的结合方式。

## 2. 版本内容
- 首批产品：禅香蜡烛、合香线香、禅香丸、香薰石膏牌、香插、禅修体验套装
- 风格关键词：安静、疗愈、东方、沉静、仪式感
- 设计方向：飞虹塔、金藏、霍泉、古柏、寺庙香火

## 3. 规格参数
- 香品：线香、香丸、蜡烛、石膏牌、香插、礼盒
- 工艺：合香、炼蜜、灌注、雕刻、包装

## 4. 成本与售价
- 材料成本：¥3–120
- 建议售价：¥38–498
- 套装价可达更高客单

## 5. 适用场景
- 家居香氛
- 送礼
- 禅修体验
- 内容传播

## 6. 生产注意事项
- 香方配比要稳定
- 线香、香丸需要完整晾干
- 礼盒中视觉与功能要统一

## 7. 风险与限制
- 香味偏好差异大
- 制作流程需要耐心
- 体验产品对叙事要求较高
