# 开发路径

## 1. 开发目标
- 用地域 IP 元素形成可销售的文创产品
- 先跑通一个低成本样板，再决定是否扩展矩阵

## 2. 路径阶段
### 阶段1：概念验证
- 提取核心 IP 元素
- 选择产品载体
- 形成概念草图

### 阶段2：打样测试
- 完成样品制作
- 验证视觉与工艺
- 拍摄基础物料

### 阶段3：试销上线
- 小批量投放
- 线上种草与线下试卖
- 收集反馈

### 阶段4：规模化迭代
- 根据反馈优化系列化产品
- 扩展 SKU 与定制选项

## 3. 当前首轮路径
- 母题：广胜寺 / 飞虹塔 / 洪洞地域纹样
- 载体：纸品布艺
- 首批样品：明信片、书签、便签本、帆布袋
- 目标：先验证图案表达、成本和传播效果

## 4. 关键里程碑
- 完成 IP 元素库
- 完成 2–3 个首批产品样品
- 完成首轮内容测试
- 明确是否继续扩展到琉璃或香道品类

## 5. 资源需求
- 设计
- 打样
- 拍摄
- 渠道测试

## 6. 风险点
- IP 选择过散
- 产品太多导致定位模糊
- 工艺与成本不匹配
