## 发布频率与最佳时间

```
频率：每天1条（前30天必须保持日更）
      → 做不到日更 → 至少每周5条
      → 周末可以提前一天做好，定时发布

最佳发布时间（流量高峰）：
  工作日：中午12:00-13:00 和 晚上19:00-21:00
  周末：上午10:00-11:00 和 晚上20:00-22:00

发布时间策略：
  先发1周 → 看数据 → 哪条数据好 → 那个时间段就是你的最佳发布时间
```

## 内容制作时间分配（每天2小时）

```
制作过程视频（最耗时）：90分钟
  拍摄(45min) → 粗剪(30min) → 配文字(15min)

产品展示图文（中等）：60分钟
  摆拍(30min) → 选片+修图(20min) → 写文案(10min)

文化科普（最省时）：45分钟
  找资料(15min) → 写文案(20min) → 配图(10min)

互动随拍（最随意）：30分钟
  随手拍(10min) → 写心里话(20min)
```

## 互动技巧（提升算法推荐）

```
每条内容结尾都加上互动引导（选1-2个）：

  "你最喜欢哪个颜色？评论区告诉我"
  "你们觉得冰箱贴卖多少钱合适？"
  "有人去过广胜寺吗？分享一下你的经历"
  "下一期想看什么？点赞+收藏，我继续做"
  "猜猜这枚香囊是用什么香粉配的？"

不要在结尾写"购买链接在主页"（会被限流）
正确做法：个人简介写"私信咨询" → 受众私信 → 转微信成交
```
