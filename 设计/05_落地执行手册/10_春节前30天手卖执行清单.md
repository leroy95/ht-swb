# 春节前30天手卖执行清单（V1.0.0）

> **目标**：春节前先用小批量、低风险、可拍照的小件和礼盒，手动卖一卖，验证哪些最容易成交
> **适用场景**：朋友圈预售、年货摊、社区集市、唐装店寄卖、亲友圈试卖
> **原则**：先小批试卖，不先大货；先礼盒，再单品；先收订金，再补货

---

## 1. 30天节奏总览

| 阶段 | 时间 | 重点 |
|---|---|---|
| 准备期 | D-30 ~ D-22 | 定主推款、定价格、定礼盒、定话术 |
| 预热期 | D-21 ~ D-15 | 出样拍图、朋友圈预热、收第一轮意向 |
| 试卖期 | D-14 ~ D-8 | 社区集市/年货摊/唐装店/熟人圈试卖 |
| 冲刺期 | D-7 ~ D-1 | 集中包装、补单、最后一轮朋友圈推送 |
| 收口期 | 除夕前 | 发货、交付、补货、统计数据 |

---

## 2. 春节主推 6 款建议

1. **春节红金冰箱贴礼盒**：最适合朋友圈预售和年货摊
2. **春节限定明信片套装**：适合搭配红包、贺卡、伴手礼
3. **姓氏 / 家谱卷轴礼品版**：返乡、走亲访友、寻根场景
4. **红金香囊**：手工感强，春节礼感足
5. **节庆发钗 / 压襟小套装**：适合唐装、年会、拜年穿搭
6. **祝福语书签 / 祈福丝带**：低价引流，顺手成交

---

## 3. 30天每天做什么

### D-30 ~ D-24：定主推、定样品

| 天 | 动作 | 目的 |
|---|---|---|
| D-30 | 确定春节主推 3–6 款，砍掉不必要 SKU | 收窄战线 |
| D-29 | 定每款售价、礼盒组合、赠品规则 | 统一口径 |
| D-28 | 定春节配色：红、金、米白为主 | 形成年味 |
| D-27 | 出第一版图稿，确认是否适合送礼场景 | 减少返工 |
| D-26 | 做 1 轮样品，拍 3–6 张朋友圈素材 | 先有图再卖 |
| D-25 | 给亲友看样品，问“愿不愿意买、送谁” | 先测反应 |
| D-24 | 根据反馈微调包装和文案 | 优化成交点 |

### D-23 ~ D-17：预热、试问价

| 天 | 动作 | 目的 |
|---|---|---|
| D-23 | 发朋友圈预热图 1：春节限定、先订先发 | 开始埋点 |
| D-22 | 发朋友圈预热图 2：礼盒拆图/细节图 | 建立礼感 |
| D-21 | 发朋友圈预热图 3：告诉大家“先做小批量” | 降低决策门槛 |
| D-20 | 找 5–10 个熟人试问价 | 看价格接受度 |
| D-19 | 统计问得最多的款、最多的价位 | 找主销款 |
| D-18 | 决定首批每款做 20–50 套，不再扩品类 | 防止压货 |
| D-17 | 开始收第一轮预定（订金 30%–50%） | 锁单 |

### D-16 ~ D-10：试卖、试场景

| 天 | 动作 | 目的 |
|---|---|---|
| D-16 | 去社区集市 / 年货摊试摆一次 | 看现场反应 |
| D-15 | 去唐装店寄样或试陈列 | 看搭配效果 |
| D-14 | 更新朋友圈：展示第一轮预定情况 | 形成稀缺感 |
| D-13 | 做第二轮小补货，只补热卖款 | 控库存 |
| D-12 | 做送礼场景文案：送长辈、送亲友、送老师 | 增强购买理由 |
| D-11 | 再去一轮线下手卖（亲友聚会/小市集） | 继续测单 |
| D-10 | 汇总：哪款最容易成交、哪款最被问 | 定最终主推 |

### D-9 ~ D-4：集中包装、补单、提速度

| 天 | 动作 | 目的 |
|---|---|---|
| D-9 | 只保留 2–3 个最稳 SKU | 收口 |
| D-8 | 集中包装、贴标签、配礼袋 | 让货像礼物 |
| D-7 | 朋友圈最后一轮推送：截止预订时间 | 冲单 |
| D-6 | 补发未确认订单，整理地址表 | 降低发错 |
| D-5 | 复核礼盒数量、配件、说明卡 | 防漏件 |
| D-4 | 打包发货第一批，留出物流缓冲 | 防延误 |

### D-3 ~ 除夕前：收口、交付、清库存

| 天 | 动作 | 目的 |
|---|---|---|
| D-3 | 发最后一轮“春节前最后一批”提醒 | 收尾成交 |
| D-2 | 只处理补单、发货、核对地址 | 不再扩散 |
| D-1 | 现场交付 / 同城送达 / 上门取货 | 完成交付 |
| 除夕前 | 统计销售数据、礼盒销量、朋友圈转化 | 为节后复盘准备 |

---

## 4. 手卖成交话术

- “这是春节前最后一批，先订先发。”
- “适合送长辈 / 亲友 / 拜年，礼盒已经配好。”
- “先试卖小批量，卖得动再补，不会一下子压很多。”
- “想送得体面一点，可以直接选礼盒版。”
- “可以先付订金，我这边按顺序发货。”

---

## 5. 价格建议

| 类型 | 建议价格带 | 说明 |
|---|---:|---|
| 引流款 | ¥5–22 | 书签、丝带、单张明信片 |
| 主卖款 | ¥38–68 | 冰箱贴、香囊、单件礼品 |
| 礼盒款 | ¥68–168 | 最容易在春节成交 |
| 形象款 | ¥168+ | 只做少量，强调体面与故事 |

---

## 6. 订金与库存规则

- 每款先做 **20–50 套**
- **先收订金再生产**，订金建议 30%–50%
- 只补热卖款，不扩不稳的 SKU
- 卖不动的春节后改包装或清库存

---

## 7. 重点判断标准

- 哪款被问最多 → 下一轮优先补哪款
- 哪个价位最好成交 → 春节主推哪个价位
- 哪种包装最像“送礼” → 春节优先用哪种包装
- 哪个渠道最容易成交 → 节后把资源往那个渠道倾斜

---

## 8. 节后处理

- 卖得好的 1–2 款，直接转成常态 SKU
- 卖得一般的，改包装再卖
- 卖不动的，春节后清库存或作为赠品

---

> 这份清单的目标不是把春节做大，而是把春节前的成交路径跑通：**先看图、再问价、再收订、再发货**。
