# 🚨 风险应对速查卡

> **用法**：遇到问题→翻到对应卡片→按步骤执行
> **原则**：不慌、不乱、不变形——每个问题都有预案

---

## 🃏 卡片1：景区谈不下来

### 症状
- 广胜寺景区商店拒绝合作
- 或者要的分成太高（40%+）

### 应对步骤

```
第1步：先问清楚原因
  → "是分成比例的问题？还是产品的问题？还是你们有其他顾虑？"
  → 了解真正原因才能针对性解决

第2步：换谈判对象
  → 官方店不行 → 找景区内个体商户（决策快，分成20-25%）
  → 景区门口/停车场旁边的商店也算（游客必经之路）

第3步：用数据说话
  → 先在夜市摆摊2周 → 记录日销¥300-500 → 
  → 拿着真实的销售数据回去谈：
     "夜市一天卖¥500，放你景区只会更高"

第4步：如果所有景区渠道都走不通
  → 全力攻线上渠道（拼多多+抖音小店+朋友圈）
  → 每周夜市+市集 → 最大化线下自有渠道
  → 3个月后有了线上销量数据 → 再回头谈景区
```

### 止损点
```
如果第3个月底：
  → 广胜寺、大槐树、苏三监狱全部谈不下来
  → 线上月销也不到¥2,000
  → 考虑是否调整轨道A的产品/定位/定价
```

## 🃏 卡片2：产品卖不动

### 症状
- 第一批货到店2周，销量远低于预期
- 广胜寺日均游客1500人，但每天只卖1-2件

### 应对步骤

```
第1步：定位问题根源（一次只测一个变量）

  变量1：产品本身
    → 让朋友/游客看产品 → 直接问"你不买的真实原因？"
    → 太贵？不好看？不知道是什么？没有购买冲动？
  
  变量2：陈列位置
    → 产品放在商店的哪个位置？收银台旁边？角落？
    → 收银台旁边=冲动消费区（转化率最高）
    → 角落=没人看到
  
  变量3：价格
    → 尝试降价测试：¥38降到¥29 → 销量有变化吗？
    → 降价20%测试1周 → 如果销量翻倍 → 说明定价偏高

第2步：根据原因调整

  设计不好看 → 暂停补货这款 → 改设计 → 下一批上新
  价格太高 → 降价到有竞争力的位置
  陈列位置不好 → 跟商店沟通换到人流大的位置
  没人知道 → 在景区门口/售票处放宣传卡

第3步：夜市清仓
  → 卖不动的产品 → 夜市摆摊 → ¥15-20降价清 → 回本优先
  → 不要心疼 → 清出来的现金比压在库房有用
```

### 止损点
```
一款产品连续3周周销<5件 → 清仓处理 → 不补货
15款中有8款以上卖不动 → 设计方向有根本问题 → 重新调研
```

## 🃏 卡片3：招不到/留不住妇女

### 症状
- 发招募通知没人来
- 培训了2天就不来了
- 品质不稳定、经常返工

### 应对步骤

```
第1步：检查招募渠道
  → 微信群发了但没人回？→ 换渠道
  → 找村委妇女主任（最有信任感）
  → 去村里/社区活动室贴纸质通知
  → 夜市摆摊时挂招募牌

第2步：检查"第一天体验"
  → 第1天就让人做难的 → 挫败感 → 不来了
  → 正确做法：第1天只做石膏牌（调浆→脱模→完成）
  → 1天后拿到成品+第一笔手工费 → 有成就感 → 愿意继续

第3步：检查结算
  → 有没有按时发钱？
  → 有没有克扣？（瑕疵品扣太多会让人心寒）
  → 新手报废率放宽到10% → 给容错空间

第4步：保持弹性
  → 不强求每天做多少 → 有单就做
  → 允许"这周有事暂停一周"
  → 只要品质过关、按时交活 → 不干涉她们怎么安排时间
```

### 止损点
```
如果第3月底还是招不到人：
  → 轨道B自己继续做（产量少但利润高，也能养自己）
  → 轨道A组装工作也可以自己做（每周2-3天集中分装）
  → 等订单量真的上来了，招人的紧迫感才真实
```

## 🃏 卡片4：现金流断裂

### 症状
- 账户余额在第8周后急剧下降
- 第10周余额<¥3,000
- 大货付了但还没到，手上没钱了

### 应对步骤

```
第1步：立即停止所有非必要支出
  → 暂停新品类开发
  → 暂停营销推广
  → 暂停第二批下单
  → 自己生活费压到最低

第2步：加速回款
  → 联系工厂催货（货到了才能卖）
  → 夜市天天摆摊（最快的现金流来源）
  → 朋友圈推一波特价（老客户8折预售）
  → 如果有轨道B订单 → 优先交付 → 先收钱

第3步：短期周转
  → 跟工厂商量尾款分期（"先付一半，剩下的下个月"）
  → 跟景区商量改周结（之前月结→改成周结）
  → 接定制单收全款（不赊账）

第4步：评估是否继续
  → 如果第3-4月累计现金流< -¥25,000
  → 认真考虑：继续投还是止损？
  → 止损标准：再投¥3,000看不到回本希望 → 停
```

### 预警信号
```
⚠️ 余额 < ¥5,000 且下一笔收入在2周后 → 红色警报
⚠️ 连续2周没有任何收入 → 黄色警报
⚠️ 工厂催尾款但货还没到 → 沟通缓冲期
```

## 🃏 卡片5：品质出问题（大货质量差）

### 症状
- 打开箱子发现工厂做的跟样品不一样
- 色差严重/珐琅填色溢出/印刷模糊

### 应对步骤

```
第1步：立即拍照取证
  → 样品照片 vs 大货照片 → 并列对比
  → 标注具体问题（色差/毛刺/印刷问题）
  → 统计瑕疵比例

第2步：联系工厂
  → 发对比图 → 要求解释
  → 瑕疵<5%：正常，要求退差额
  → 瑕疵5-15%：要求退差额+补发好品
  → 瑕疵>15%：要求整批退回重做/全额退款

第3步：如果工厂不认
  → 1688订单→申请平台介入→上传证据
  → 平台通常偏向买家（尤其有实物对比证据）
  → 微信私下交易→无法维权→以后不在微信私下交易

第4步：这批货怎么处理
  → 轻微瑕疵：自己挑出好的→正常卖→瑕疵品夜市低价出
  → 严重瑕疵：退工厂→换供应商→推迟该品类上架
```

### 预防措施
```
✅ 打样确认后再下大货（最重要）
✅ 大货要求工厂寄"产前样"（生产前抽1件出来确认）
✅ 首次合作不走微信私下交易（走1688有平台保障）
✅ 保留所有聊天记录+样品照片
```

## 🃏 卡片6：唐装店试点失败

### 症状
- 放样品1个月，一件没卖出去
- 店员不推荐/客户不感兴趣

### 应对步骤

```
第1步：确定问题
  → 是店员没推荐？（嘴上答应但不推→没动力）
  → 还是推荐了客户不买？（看了但觉得贵/不好看/不需要）

第2步：店员不推→给激励
  → 店员卖出一件 → 额外给店员¥10-20/件（不是给店，是给个人）
  → 店员卖够5件 → 送一件产品给她自己
  → 让自己有动力帮你推

第3步：客户不买→改产品
  → 直接问买了唐装的客户（加微信问）
  → "您觉得这个发钗贵吗？还是款式不喜欢？"
  → 根据反馈调整：款式/价格/搭配方式

第4步：试点失败也不意味着放弃
  → 换一家唐装店再试
  → 改做线上唐装配搭内容（小红书推"旗袍+压襟"穿搭）
  → 参加汉服市集（线下直面用户，直接听到反馈）
```

## 🃏 卡片7：自己坚持不下去了

### 症状
- 每天很累但看不到成果
- 第4-6周最容易放弃
- 怀疑"我在干嘛？"

### 应对

```
① 回头看→已经做了多少？
  第1周你什么都没有 → 第6周你有了15款设计、样品、小红书账号、
  工厂在打样、夜市摆了3次 → 这不是"没有成果"

② 降低期望→重新定义"成功"
  第1年的成功 = 不是赚多少钱
             = 跑通模式（产品有人买+工厂能交货+妇女能出活）
             = 还活着（账户余额>0）
  
③ 找人聊→别一个人扛
  跟合作方聊（做唐装的朋友）：他们怎么熬过第一年？
  跟同行聊（小红书上的手工博主）：加微信请教经验

④ 如果真的太累→停1周
  暂停小红书日更（改成周更2-3次）
  暂停夜市（休息1周）
  只保留轨道B接单（有收入）
  休息一周不叫失败，叫调整节奏
```
