# 🔐 IP 授权策略

> **核心问题**：用广胜寺/大槐树的形象做商业产品，合法吗？
> **一句话结论**：洪洞目前没人管这事。先做，但要知道边界在哪里。

---

## 一、法律边界：什么能做、什么有风险

### 三种情况

| 情况 | 风险等级 | 说明 | 例子 |
|------|:---:|------|------|
| **公共领域** | 🟢 安全 | 古建筑本身没有版权（著作权保护期50年，早已过期）。建筑外观属于公共领域。 | 画飞虹塔的轮廓剪影做冰箱贴 |
| **公有元素** | 🟢 安全 | 文物/壁画/经文属于全人类的公共文化资源，可以用于创作。 | 赵城金藏经文片段做书签 |
| **景区官方标识** | 🔴 踩雷 | 景区注册的商标/logo/官方名称不能直接用。 | 不能直接用"广胜寺®"注册商标做产品 |
| **他人摄影作品** | 🔴 踩雷 | 网上下载的广胜寺照片有摄影师版权，不能直接用 | 不能从百度图片下载照片印明信片 |

### 实操总结

```
✅ 可以做的（安全）：
  → 自己画飞虹塔的线描/插画 → 做成产品
  → 提取琉璃塔的7种颜色 → 做成配色体系
  → 提取壁画的纹样/飞天形象 → 二次创作
  → 提取建筑局部（斗拱/脊兽/琉璃瓦）→ 做成冰箱贴

⚠️ 注意方式（基本安全）：
  → 产品上写"飞虹塔"（建筑名字，公共领域）
  → 产品描述写"灵感来源于广胜寺"
  → 不直接使用"广胜寺×品牌"联名字样

❌ 不要做（风险大）：
  → 印景区官方logo
  → 声称"广胜寺官方授权"（如果没有）
  → 用别人拍的照片直接印刷
```

## 二、三条路（选择你的策略）

### 路线A：先做再说（推荐起步阶段）

```
逻辑：洪洞目前没人管文创IP授权 → 我们先做 → 
      做起来了景区主动找我们 → 那时候再谈正规授权

适用阶段：第1-12个月
风险：低（文物建筑本身没有版权，我们做的是二次创作）
唯一风险：如果产品卖爆了，景区可能会来找你"谈谈"
         → 那时候你就有谈判筹码了（我们帮你景区增加了曝光）

实操要点：
  → 所有设计都是"原创插画/二次创作"，不是直接复制照片
  → 产品说明写"灵感来源于飞虹塔/广胜寺壁画"
  → 不写"广胜寺官方授权""广胜寺联名"
```

### 路线B：主动谈授权

```
逻辑：做起来有基础销量后 → 主动找景区管委会谈授权 → 
      拿到正规授权，名正言顺，还能用"官方授权"做营销

适用阶段：第6-12个月（有一定销量基础后）
谈判筹码：
  ① "我们已经在广胜寺景区商店卖了X个月，月销¥XX,XXX"
  ② "我们的文创产品在小红书/抖音有XX万曝光"
  ③ "授权给我们，你们景区多了一个文创名片"
  ④ "我们付费授权（¥2,000-5,000/年），不贵但名正言顺"

授权谈判对象：
  洪洞县文物旅游局 / 广胜寺文物管理所 / 景区管委会
  （通常文物归文物局管，景区运营归管委会管，要搞清楚）
```

### 路线C：只做通用文创（最安全）

```
逻辑：不做任何广胜寺IP，只做通用中式文创 → 没有任何授权问题

适用：如果广胜寺明确拒绝了授权，或者法律风险评估后决定不做

例子：
  → 不做飞虹塔冰箱贴 → 做"中国古建系列"冰箱贴
  → 不做飞天壁画丝巾 → 做"敦煌色系"通用丝巾
  → 不做金藏经文 → 做"古风"通用手账

缺点：失去地域独特性，回到轨道A的"普通景区文创"
```

### 推荐组合

```
第1-6月：路线A（先做再说）
  → 二次创作设计，规避直接复制
  → 专注做产品、跑渠道

第7-12月：根据情况决定
  → 产品卖得好 → 走路线B（主动谈授权）
  → 景区来找了 → 顺势谈判
  → 有法律风险信号 → 部分品类走路线C
```

## 三、产品命名规范（实操版）

### 产品上可以写的

```
✅ "飞虹塔"（建筑名称，公共领域）
✅ "灵感来源于山西洪洞"
✅ "琉璃色谱系列"
✅ "元代壁画风格"
✅ "洪洞文创"
```

### 产品上不要写的

```
❌ "广胜寺官方文创"
❌ "广胜寺×XX联名"
❌ 使用广胜寺官方Logo
❌ "广胜寺®授权"
```

### 设计上的安全做法

```
原始壁画 → 提取元素 → 二次创作 → 产品图案
  |            |           |            |
飞天人物    → 提取线描  → 风格化简化  → 丝巾/明信片
飞虹塔照片  → 手绘插画  → 几何色块化  → 冰箱贴
琉璃砖实物  → 提取色彩  → 7色系统    → 全系列配色
```

## 四、万一出了问题的应对

### 场景1：景区管理处打电话来"你们在用广胜寺形象？"

```
冷静应对（不要慌）：
  ① "我们的产品是原创插画设计，灵感来源于飞虹塔这座古建筑"
  ② "古建筑本身属于公共文化资源，我们做的是艺术二次创作"
  ③ "我们也希望跟景区合作，如果您愿意给我们授权，我们可以正式签约"
  ④ "我们的产品在小红书/抖音已经有XX曝光，对景区也是一种宣传"

大概率结果：
  → 对方其实只是问问（景区没有专门的法务团队管这个）
  → 顺势聊合作（"我们已经在景区商店卖了""给我们授权，产品更名正言顺"）
  → 最差情况：承诺改产品描述（改一下措辞就行了）
```

### 场景2：收到律师函

```
概率：极低（洪洞本地没有文创法务团队，国内景区文创IP诉讼极少）
应对：①停止该产品生产销售 → ②改设计重新上市 → ③损失可控（首批只200件）
```
