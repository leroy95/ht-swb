## 这个手册解决什么问题

### 商业计划书的问题
商业计划书告诉你：应该做什么、为什么做、花多少钱。
但它不负责回答：具体怎么操作、第一步先做什么、打样后怎么验、出问题怎么办。

### 这个手册补上的内容
- 不知道去哪找工厂 → 看 `02_供应商开发实操.md`
- 不知道怎么拍产品图 → 看 `03_产品拍摄指南.md`
- 不知道每天干嘛 → 看 `07_每周执行清单.md`
- 不知道质检和返工怎么处理 → 看 `08_风险应对速查卡.md`
- 不知道整条生产线怎么排期和交接 → 看 `09_制作落地执行方案.md`

## 使用原则

1. 先看总纲，再看明细
2. 先样品，再小批量，再放量
3. 先规则清楚，再开始生产
4. 任何新增内容都要回到“谁做、做什么、多少钱、多久做完”
