## ⚡ 这个手册解决什么问题？

### 商业计划书的问题

```
商业计划书告诉你：应该做什么、为什么做、花多少钱
但没有告诉你：具体怎么操作、第一步打开什么网站、给工厂发什么话

这个手册补上操作层：
  → 发小红书不知道怎么拍 → 翻到03_产品拍摄指南
  → 不知道去哪找工厂 → 翻到02_供应商开发实操
  → 景区IP能不能用不敢确定 → 翻到01_IP授权策略
  → 每天不知道干嘛 → 翻到07_每周执行清单
```
