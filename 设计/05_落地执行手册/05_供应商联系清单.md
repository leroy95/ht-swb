### 评估状态标记

```
🟢 已合作：出过大货，品质稳定，可以长期合作
🟡 洽谈中：问过价，还没下单，等有需求再联系
🔴 已淘汰：品质差/交期拖延/坐地起价，不合作了
⚪ 备选：收藏了但还没联系
```

## 四、维护规则

```
① 每次询价后立刻更新（不要等明天，明天就忘了）
② 每季度清理一次：超过3个月没联系的→备注"备选"
③ 每个品类至少有2个备用供应商（以防万一）
④ 合作过的标记🟢，以后同品类优先找他（老客户好谈价）
⑤ 淘汰的标记🔴+写清楚原因（防止以后忘了又去问）
```
