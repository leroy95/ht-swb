## 一、选品逻辑

### 适合家庭妇女的手工产品，必须满足 5 个条件：

```
✅ 能在家里做（不需要大型设备、不产生污染/噪音）
✅ 学习曲线短（1天–2周内能上手）
✅ 容错率高（做错了可以修正，不是一步错全报废）
✅ 原料安全（无毒无害，孩子在家也不怕）
✅ 有稳定订单（做出来有人买，不是做了白做）
```

## 二、9 种手工完整拆解

### 🥇 品类一：石膏翻模冰箱贴/摆件

#### 做什么

```
飞虹塔建筑局部 → 石膏翻模 → 手工上色 → 成品冰箱贴

具体产品：
  → 斗拱冰箱贴（5cm×5cm）
  → 脊兽冰箱贴（4cm×6cm）
  → 琉璃瓦当冰箱贴（直径5cm圆形）
  → 佛龛冰箱贴（4cm×7cm）
  → 塔形摆件（8cm高，非冰箱贴）
```

#### 操作流程

```
步骤1：调石膏浆（2分钟）
  高强石膏粉 : 水 = 100g : 30–35g
  搅拌至无颗粒的酸奶状

步骤2：灌模（1分钟）
  将石膏浆倒入硅胶模具
  轻敲模具边缘震出气泡

步骤3：凝固等待（20–30分钟）
  石膏发热→冷却→完全凝固

步骤4：脱模（1分钟）
  轻轻掰开硅胶模具取出石膏件
  检查有无气泡/残缺

步骤5：修整（2分钟）
  砂纸打磨毛边、修整细节

步骤6：上色（5–10分钟）
  丙烯颜料逐层上色
  参照色卡，先铺底色再画细节
  等每层干了再叠下一层

步骤7：封层（1分钟喷涂+4小时干燥）
  喷哑光/亮光清漆保护

步骤8：贴磁铁+挂配件（2分钟）
  背面用强力胶贴强磁铁
  （挂件款：穿绳/装配件）

单件总工时：15–25分钟（不含凝固和干燥等待）
```

#### 学习路径

```
第1天上午（3小时）：
  → 认识材料 → 调浆示范 → 灌模实操 → 脱模
  → 每人做3–5件，练习手感
  → 重点：调浆不能太稀/太稠（这是最容易出错的地方）

第1天下午（3小时）：
  → 上色教学 → 色卡对照 → 基础技法（平涂/渐变/做旧）
  → 每人上色3件练习

第2天：
  → 完整流程独立做一遍（从调浆到包装）
  → 培训师逐件检查 → 指出问题 → 修正
  → 考核：连续3件达标 → 可以接单

达标标准：
  ✅ 表面无气泡
  ✅ 颜色均匀、边界清晰
  ✅ 磁铁贴正、牢固
  ✅ 包装整洁
```

#### 收入测算

```
单件手工费：¥8–12（按品类和复杂度）
日产量（4h）：10–15件
日收入：¥80–180
月收入（20天）：¥1,600–3,600

加上奖金（全勤+质量+超产）→ 月入 ¥2,000–4,500
```

### 🥇 品类二：古法香囊

#### 做什么

```
裁布 → 缝合 → 翻面 → 填香 → 收口 → 穿绳 → 流苏 → 完成

具体产品：
  → 飞虹清韵香囊（檀香+柏木，琉璃蓝布料）
  → 金藏书香香囊（藿香+丁香，米黄布料）
  → 霍泉芳草香囊（艾草+薄荷，浅绿布料）
```

#### 操作流程

```
步骤1：裁布（1分钟）
  按模板裁剪两块 14cm×14cm 布料
  （品牌方提供裁好的布片→更简单）

步骤2：缝合三面（5分钟）
  两块布正面相对 → 缝三面（缝纫机或手缝均可）
  留 3cm 翻口

步骤3：翻面（1分钟）
  从翻口翻出正面

步骤4：填香（2分钟）
  填入香粉+棉花混合物
  注意：香粉在中间、棉花包裹在外（香味均匀散发）

步骤5：收口（3分钟）
  藏针法缝合翻口 → 线迹不外露

步骤6：穿绳（2分钟）
  距袋口2cm处缝穿绳通道 → 穿入棉绳

步骤7：打流苏结（2分钟）
  用同色棉线做流苏 → 绑在绳尾

步骤8：检查+包装（2分钟）
  检查缝线是否整齐 → 装入包装袋

单件总工时：15–20分钟
```

#### 学习路径

```
第1天上午（3小时）：
  → 认识布料和香粉 → 缝合练习（缝直线）
  → 重点：藏针法收口（这是最容易露馅的地方）

第1天下午（3小时）：
  → 完整流程做3个 → 逐个检查缝线和香粉

第2天：
  → 独立做5个 → 考核
  → 达标标准：缝线整齐无外露、香粉量合适、流苏对称
```

#### 收入测算

```
单件手工费：¥8–12
日产量（4h）：12–16个
日收入：¥96–192
月收入（20天）：¥1,920–3,840
```

### 🥈 品类三：浮雕蜡烛

#### 做什么

```
融蜡 → 调色调香 → 入模 → 脱模 → 基础雕刻或精细雕刻

两个级别：
  基础款 → 简单几何纹样雕刻 / 文字雕刻 → 2周可上手
  精细款 → 飞虹塔/飞天/花纹精细浮雕 → 3–6周可上手
```

#### 操作流程（基础款）

```
步骤1：融蜡（15分钟）
  大豆蜡放入融蜡锅 → 隔水加热至 75–85°C 完全融化

步骤2：调色调香（3分钟）
  滴入色粉搅拌均匀 → 降温至 55–65°C → 滴入精油

步骤3：入模（2分钟）
  倒入硅胶模具 → 插入木片烛芯 → 固定居中

步骤4：冷却凝固（1–2小时）
  自然冷却至室温 → 不要放冰箱（会裂）

步骤5：脱模（2分钟）
  轻轻脱出蜡柱 → 检查有无气泡/裂纹

步骤6：雕刻（基础款 15–25分钟 / 精细款 40–90分钟）
  蜡柱微温状态（约30°C）→ 用雕刻刀刻纹样
  基础款：刻简单的回纹、如意纹、文字
  精细款：刻塔形轮廓、飞天剪影、缠枝纹

步骤7：修整+检查（5分钟）
  修整雕刻毛边 → 擦拭蜡屑 → 整体检查

单件总工时：基础款 40–60分钟 / 精细款 70–120分钟
```

#### 学习路径

```
基础款（2周）：
  第1周 → 学融蜡+入模+脱模 → 每天做2–3件练手感
  第2周 → 学基础雕刻（直线刻、曲线刻、简单纹样）→ 独立完成

精细款（3–6周）：
  第3–4周 → 学复杂纹样雕刻（缠枝纹、回纹、花卉）
  第5–6周 → 学飞虹塔浮雕 → 学飞天人物浮雕
  第7–8周 → 可独立完成品牌完整产品

关键难点：蜡温控制（太高烫手雕不动，太低蜡太硬刻不动）
         最佳雕刻温度是蜡体微温（28–32°C）
         这个手感只能靠反复练习建立
```

#### 收入测算

```
基础款手工费：¥15–20/件 → 日产(4h) 4–6件 → 月入 ¥1,200–2,400
精细款手工费：¥25–50/件 → 日产(4h) 3–5件 → 月入 ¥1,500–5,000

鼓励路径（品牌方的利益）：
  → 女工从基础做到精细 → 手工费翻倍 → 品牌方产品溢价更高 → 双赢
```

### 🥈 品类四：合香线香

#### 做什么

```
香料粉 + 粘粉 + 水 → 和泥 → 挤香 → 理直 → 晾干 → 切齐 → 包装
```

#### 操作流程

```
步骤1：配料（5分钟）
  按香方卡配比称量香料粉+粘粉 → 混合均匀
  （品牌方提供预混好的香粉包→更简单）

步骤2：和泥（10分钟）
  少量多次加水 → 揉成面团状
  标准：能成团、不粘手、不散开

步骤3：醒泥（30分钟）
  保鲜膜包好 → 静置（让水分均匀渗透）

步骤4：挤香（15–20分钟）
  放入手动挤香器 → 匀速挤出直径2–3mm 的线香条
  → 直接挤在晾香板上排列整齐

步骤5：理直（5分钟）
  用直尺轻压线香条 → 理直 → 保持均匀间距

步骤6：晾干（2–5天）
  阴凉通风处自然晾干
  ⚠️ 不能晒！晒太阳会开裂或变味
  ⚠️ 每天翻面一次保证均匀干燥

步骤7：切齐+包装（10分钟）
  干透后用剪刀裁成15cm标准长度
  → 装入纸管/竹筒 → 贴标签

单批工时：约50分钟操作 + 2–5天晾干
（晾干期间可以同时做其他活）
```

#### 收入测算

```
单管手工费（含切齐包装）：¥10–15
日产（操作部分4h）：10–15管（同时多批晾干中）
月收入（20天）：¥2,000–4,500
```

### 🥈 品类五：香薰石膏牌

#### 做什么

```
石膏粉+水+精油调浆 → 灌模 → 脱模 → 穿绳 → 包装
```

#### 操作流程

```
步骤1：调浆（3分钟）
  石膏粉100g + 水35g + 精油5–10滴 → 搅拌至酸奶状

步骤2：灌模（1分钟）
  倒入硅胶模具（塔形/飞天形/莲座形/柏叶形）

步骤3：凝固（15–20分钟）
  石膏发热→冷却→硬化

步骤4：脱模（1分钟）
  取出 → 检查有无残缺

步骤5：穿绳（2分钟）
  穿入棉麻绳 → 打结

步骤6：包装（1分钟）
  装入透明袋 → 贴标签

单件总工时：5–8分钟
```

> 这是所有品类里**最简单、最快、最容易上手**的——适合刚入门的妇女做第一件练手产品。

#### 收入测算

```
单件手工费：¥3–5
日产量（4h）：30–50件
日收入：¥90–250
月收入（20天）：¥1,800–5,000
```

### 🥉 品类六：环氧树脂基础件（杯垫/摆件）

#### 注意事项

```
⚠️ 环氧树脂操作需要通风环境（AB胶混合有轻微气味）
⚠️ 需要戴手套操作（树脂粘皮肤不好洗）
⚠️ 对精准度要求高（AB胶配比严格，多一克少一克都会不固化）
⚠️ 固化时间 8–24 小时（期间不能动）
```

#### 操作流程

```
步骤1：配胶（5分钟）
  A胶 : B胶 = 3 : 1（重量比，必须用电子秤精确称量）
  同一方向慢速搅拌2–3分钟 → 减少气泡

步骤2：调色（2分钟）
  加入色精/珠光粉 → 搅拌均匀

步骤3：第一层灌注（3分钟）
  倒入模具底 → 厚度2–3mm → 静置消泡5分钟

步骤4：第一层固化（8–12小时）
  盖防尘罩 → 等待固化（不能动！）

步骤5：放花材+第二层灌注（5分钟）
  在固化好的第一层上摆放干花 → 灌注第二层覆盖

步骤6：第二层固化（8–12小时）

步骤7：封层+最终固化（3分钟操作+24小时固化）

步骤8：脱模+打磨（10分钟）
  400目→800目→1500目→3000目砂纸逐级打磨
```

> 树脂对**耐心和精准**要求高，但不是难——是**繁琐**。适合做事特别仔细的妇女。

#### 收入测算

```
单件手工费：¥8–15
日产量（操作时间4h）：8–12件（多件同时在不同固化阶段）
月收入（20天）：¥1,280–3,600
```

### 🥉 品类七：丝巾手工卷边

#### 做什么

```
数码印花好的真丝方巾 → 手工卷边缝边
```

```
步骤1：检查（2分钟）
  检查印花有无瑕疵 → 确认正面反面

步骤4：熨烫（3分钟）

步骤5：检查+折叠包装（5分钟）
  检查四边是否平整 → 折叠 → 装入包装

单件工时：30–50分钟
```

> 适合有缝纫基础的妇女——基础不好做不了，做好了收入不错。

#### 收入测算

```
单件手工费：¥15–25
日产量（4h）：5–8条
月收入（20天）：¥1,500–4,000
```

## 三、培训体系

### 3天集中培训方案

```
地点：村里活动室 / 社区活动中心（免费借用）
时间：上午9:00–12:00 + 下午14:00–17:00

Day 1：入门体验日
  上午 → 每人试做2个品类（石膏上色+香薰石膏牌）
         目的：看看谁有手感、谁有耐心
  下午 → 选定的主打品类（如石膏翻模）完整教学
         调浆→灌模→脱模→上色→包装，全流程

Day 2：实操练习日
  上午 → 独立完成3件（培训师在旁边看+纠正）
  下午 → 品控标准讲解（什么样的合格/什么样的不合格）
         每人再做2件，互相检查

Day 3：考核上岗日
  上午 → 正式考核：连续3件达标 → 通过
         不通过的 → 再练半天 → 补考
  下午 → 讲解生产流程（怎么领料/怎么交/怎么结算）
         发第一批料 → 回家做
```

### 7天跟岗计划

```
第1–3天：每天做5件 → 拍照发群 → 培训师逐件点评
第4–5天：每天做8件 → 基本不用点评了
第6–7天：正常接单量（10–15件/天）

第7天检查：
  ✅ 连续3天无需返工 → 转为正式工
  ⚠️ 仍需返工 → 延长跟岗1周
  ❌ 连续返工+无改善 → 建议换品类
```

## 四、生产管理

### 物料流转方案


## 五、品控标准

### 各品类通过标准

#### 石膏翻模类

| 检查项 | 标准 | 不合格判定 |
|--------|------|----------|
| 气泡 | 正面无 ≥1mm 气泡 | 正面有气泡→返工打磨填补 |
| 颜色 | 与色卡对比，色差≤2个色阶 | 明显色差→返工重涂 |
| 边缘 | 光滑，无毛刺、无缺角 | 有缺角→报废 |
| 磁铁 | 居中贴牢，手动拔不掉 | 贴偏/松动→返工 |
| 尺寸 | 与标准件相差 ≤2mm | 明显偏大偏小→检查模具 |

#### 香囊

| 检查项 | 标准 |
|--------|------|
| 缝线 | 平整、无线头外露、间距均匀 |
| 收口 | 藏针法、线迹不可见 |
| 香粉 | 手感饱满、无外漏、香味对版 |
| 流苏 | 长度一致、对称、不打结 |
| 尺寸 | 与标准件误差 ≤5mm |

#### 蜡烛

| 检查项 | 标准 |
|--------|------|
| 蜡面 | 光滑无气泡、无裂纹 |
| 雕刻 | 图案清晰、深度适中 |
| 烛芯 | 居中、直立 |
| 香型 | 与标准对版（点燃后闻） |
| 重量 | 与标注误差 ≤ 5g |

#### 合香线香

| 检查项 | 标准 |
|--------|------|
| 直径 | 2–3mm，整管均匀 |
| 长度 | 15cm ± 0.5cm |
| 直度 | 肉眼看着直，无明显弯曲 |
| 燃烧 | 连续燃烧30–40分钟，不熄灭 |
| 香气 | 与标准对版 |

### 不良品处理

```
轻微瑕疵（可修复）→ 退回返工 → 修复后重新验收 → 手工费照算
  例如：颜色稍偏差、缝线不齐、边缘毛刺

重大瑕疵（不可修复）→ 报废 → 记录在案
  例如：石膏件断裂、蜡烛严重开裂、香囊香料外漏
  每月允许报废率：≤ 3%（超过部分按材料成本的50%扣除）

连续3次同类型不良 → 专项辅导 → 确认是技术问题 or 态度问题
  技术问题 → 重新培训
  态度问题 → 暂停接单一周 → 再犯则取消合作
```

## 七、常见问题预案

### Q1：妇女做了几天就不想做了？

```
原因分析：
  → 可能是品类不合适（不喜欢/学不会）
  → 可能是家庭临时有事

对策：
  → 先换品类试试（做不来雕刻→试试香囊）
  → 暂停不劝，想回来随时欢迎
  → 不要一上来就发太多料（避免材料浪费）
```

### Q2：妇女说"手工费太低了"

```
原因分析：
  → 可能确实手慢，日收入算下来低
  → 可能跟外面听到的数字在比较

对策：
  → 先算给她看：4小时 ¥60–250 = 时薪 ¥15–60
  → 对比洪洞本地：超市收银时薪 ¥12–15、饭店服务员月薪 ¥2,500
  → 手艺熟练后产量上去 → 收入自然上去
  → 推技能升级路径："学蜡烛雕刻，单价翻倍"
```

### Q3：有些人做的品质一直不过关

```
对策：
  → 第1次返工：标注问题，教她怎么改
  → 第2次返工：视频/面对面再教一次
  → 第3次返工：换更简单的品类
  → 仍不行：建议做 DIY套装分装打包（零技能门槛）
```

### Q4：订单不足，妇女没活干

```
对策：
  → 这是最关键的问题——品牌方必须保证订单
  → 没有订单=女工流失=品牌产能崩溃
  → 所以前期不要一下子招太多人（3–5人足够）
  → 订单不稳定时：优先保证核心女工的订单量
  → 淡季时：做库存（标准品不怕压货）
```

### Q5：订单爆了，产能不够

```
对策：
  → 老带新快速扩产能
  → 临时的DIY套装分装打包可以找更多人（零门槛）
  → 最核心的雕刻/手工活 → 保证核心女工不受影响
  → 短期爆单 → 先限量/预售，宁可少卖也不能出烂货
```

---

> **核心原则**：品牌的底线不是成本，是品质。女工的底线不是速度，是稳定。
> 品质稳住 → 品牌能溢价 → 女工能涨单价 → 正循环。
